# LAST ZONE — 장전 모션 노트 (v18)

v19의 팔 관통·손잡이 접촉·재파지 수정과 실제 사람 참고는 [관통 수정 노트](CLEARANCE.md)를 참고한다.

v18은 팔꿈치 궤적·어깨의 완충·아래팔 비틀림 분산과 장전 단계 연결을 개선했다. [팔 연결 수정](ARMS.md)을 참고한다. 전체 장전 시간과 탄약 규칙은 v17을 유지한다.

v17은 기존 총기별 동작을 유지하면서 손 모델·엄지 회전·접촉·단계 연결을 수정했다. [원인 분석과 손 모델 수정](HANDS.md)을 참고한다. S-12 빈 총 시작 동작만 약 0.32초 늘렸다.

## 참고와 적용 범위

참고: Activision / Infinity Ward, [Modern Warfare Initial Intel: Detailing Advancements in Animation and Authenticity](https://blog.activision.com/cn/zh/call-of-duty/2019-07/Modern-Warfare-Initial-Intel-Detailing-Advancements-in-Animation-and-Authenticity), 2019-07-02.

개발진이 설명한 총의 무게에 따른 움직임, 빈 탄창/잔탄 장전 분리, 손에 든 탄창의 연속성, 동작과 소리의 결합을 연출 원칙으로 참고했다. 원작의 에셋이나 애니메이션 데이터를 가져오지 않았고, 구체적인 손 경로와 수치는 LAST ZONE 모델에 맞춘 독자적인 절차적 애니메이션이다. 원작과 프레임 단위로 같은 동작을 재현했다는 의미는 아니다.

## 총기별 방향

| 총기 | 눈에 보이는 차이 |
|---|---|
| AR-7 | 직선 삽입, 짧게 당겨 확인한 뒤 멈치, 간결한 복귀 |
| KA-47 | 새 탄창으로 헌 탄창을 쳐내기, 앞턱 걸기, 아래쪽 손잡이 접근 |
| SC-17 | 높은 가슴 탄입대, 왼쪽 손잡이 접근, 높은 손 경로 |
| MK-14 | 탄창 앞턱을 축으로 젖힘, 긴 소총의 느린 복귀 |
| KR-98 | 왼손이 지지하고 오른손이 볼트를 조작, 열기/닫기 소리 분리 |
| S-12 | 빈 총에서 배출구 한 발, 펌프 닫기, 아래 장전구 반복 |
| M-1014 | 손잡이 고정, 배출구 한 발, 총을 더 뒤집어 빠른 튜브 장전 |
| DB-2 | 총열 꺾기, 탄피 털기, 두 발을 함께 넣고 손목으로 닫기 |
| SA-12 | 탄창 젖혀 빼서 놓기, 위쪽으로 넘어가는 손, 무게로 처지는 자세 |
| AA-12 | 드럼 들어 올리기, 두 번 두드리기와 소리, 가장 무거운 반응 |
| P-92 | 짧은 탄입대 경로, 엄지 멈치, 잔탄 탄창 보관 |
| G-18 | 높은 탄입대, 가장 빠른 교환, 손바닥을 덮어 슬라이드 조작 |
| M-1911 | 낮은 탄입대, 좁은 삽입 자세, 슬라이드 뒤끝을 집어 당김 |
| DE-7 | 긴 탄창 이동, 크게 밀어 넣음, 오래 당기는 무거운 슬라이드 |
| R-45 | 실린더 열기, 탄피 털기, 스피드로더, 손목 닫기의 4개 소리 |

탄창의 접촉점은 실제 모델의 표면으로 맞추며, 몸의 움직임은 작게 보탠다. S-12 빈 총 시작 동작 외의 장전 시간과 탄약 소모는 유지한다. 손이 탄창을 쥔 동안에는 추가 손목 회전을 적용하지 않는다.

## 확인 화면

`start.bat` 실행 → `http://localhost:8080/tools/reloads.html`

- 총기, 빈 탄창/잔탄, 재생 속도, 카메라를 선택한다.
- 타임라인으로 삽입·손잡이·복귀 순간을 멈춰 확인한다.
- `소리 켜기`를 누르면 재생 중인 모션에 소리가 붙는다. 타임라인 이동 중에는 재생하지 않는다.
- `?models=procedural`을 붙이면 에셋이 없을 때의 대체 모델도 확인할 수 있다.
- 이 화면은 `G.Player.reloadLogic`과 `G.VM.update`를 그대로 실행한다. 별도의 전시용 모션을 만들지 않는다.

## 자동 확인

Node.js와 Playwright가 설치된 환경에서 `node tools/check-reloads.cjs`를 실행한다. Chromium이 없으면 먼저 `npx playwright install chromium`을 실행한다.

실제 에셋 모델의 빈 탄창/잔탄 30가지 모션에서 240개 자세의 유효성·손 경로의 키 순서·장전 완료를 확인하고, 30/60/144 FPS 및 100ms 간격에서 제한된 탄약과 소리 사건을 360가지 조합으로 검사한다. `THREE_DIR`로 로컬 Three.js 0.160.0 경로, `CHROME_BIN`으로 실행 파일, `SHOTS`로 스크린샷 폴더를 지정할 수 있다.
