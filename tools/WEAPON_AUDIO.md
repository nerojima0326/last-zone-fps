# 빈 총 장전 속도 · 총기별 사운드 (v20)

## 장전 속도

빈 총에서 시작한 장전은 v19보다 전체 시간을 **1.35배**로 늘렸다. 예를 들어 AR-7은 1.80초에서 2.43초, KR-98은 2.48초에서 3.35초, AA-12는 2.40초에서 3.24초가 된다. 재생 속도로는 약 26% 감소다. 잔탄이 있는 장전은 기존 시간을 유지한다.

`G.Guns.reloadFactor(empty)`와 `reloadDuration(id, empty)`를 Player·Bot에서 함께 사용한다. 산탄총과 더블배럴도 시작·삽입 주기·마무리 전체에 적용한다. 시작할 때의 빈 총 여부를 유지하므로 첫 탄을 넣은 뒤 갑자기 원래 속도로 돌아가지 않는다. 손·부품의 정규화 진행률, 탄 반영, 장전구 닫힘과 소리 시각은 동일한 늘어난 시간을 사용한다. 음성 파일의 음높이를 내려서 느리게 만드는 방식은 사용하지 않는다.

## 발사 · 조작음

기존에는 여러 총이 같은 합성 발사음과 공통 클릭음을 공유했다. v20은 **15개 개별 발사음 뱅크**와 물리적 조작음 뱅크를 사용한다. 발사음마다 독립된 두 번의 발사 트랜지언트를 잘라 교대 재생하며, 자기 총과 원거리 총의 순번을 분리했다. 저음 몸통·고역·긴 잔향을 총기에 맞춰 가공하고 피크 여유를 둔다. 총성보다 장전음이 과도하게 크지 않도록 조절했다.

장전음은 탄창 분리·삽입, 손잡이 당김, 닫힘, 산탄 삽입, 마른 방아쇠 등 사건별 짧은 큐다. 총마다 속도·음색·음량·층의 조합을 구분한다. 강철 소총, 폴리머 권총, 무거운 드럼, 볼트액션, 펌프, 중절식, 리볼버의 차이를 표현한다. 장전 전체 녹음을 한 번에 재생하지 않으므로 중단한 뒤 남은 장전 소리가 계속 나오지 않는다.

사격 뒤 펌프와 볼트도 열기/닫기를 각각 실제 모션 시각에 발생시킨다. 무기 교체 때 진행 중 펌프 동작을 취소한다. 플레이어와 봇은 총기 ID를 오디오에 전달하며 기존 거리 감쇠·좌우 위치·원거리 고역 감소를 적용한다. 파일을 미리 가져와 AudioContext가 열리면 디코딩하고, 실패하면 기존 합성음으로 복귀한다. 재생이 끝난 오디오 노드는 연결을 해제하며 활성 샘플 수를 제한한다.

총성은 The Free Firearm Sound Library의 CC0 녹음, 조작음은 SpringySpringo의 **에어소프트** CC0 녹음에서 편집했다. 가상의 게임 총기에 맞춘 설계이며 모든 총의 정확한 실물 모델·구경을 녹음했다는 뜻은 아니다. 상세 매핑·저작자·가공 방법·원본 해시는 [오디오 출처](../assets/audio/weapons/CREDITS.md)와 `assets/audio/weapons/manifest.json`에 기록했다. 오디오 파일 합계는 약 0.50MB다.

모션 스튜디오 `tools/reloads.html`에서 소리를 켜 장전 시각을 확인하고 **발사음 듣기**로 선택한 총의 소리를 따로 비교할 수 있다.

## 검증

```sh
node tools/check-reloads.cjs
node tools/check-clearance.cjs
node tools/check-weapon-audio.cjs
```

- 기존 리그/탄약/소리 검사: 30개 모션·240개 자세·10,290개 연속 프레임·360개 탄약/소리 조합 통과.
- v19 팔 관통 회귀: 90개 조합·15,949개 프레임 통과. 조작 중 본체 근사 볼륨 겹침 최대 0mm, 이동/지지 최대 5.67mm.
- 16개 MP3 뱅크의 브라우저 디코딩, 15개 총의 발사·장전 출력 구분, 연사 중 유한한 샘플/출력 피크, 거리 감쇠, 총성/조작음 음량 관계, 재생 종료 후 노드 정리, 샘플 누락 시 합성음 복귀 검사.
- `BASELINE_PLAYER`에 v19의 `js/player.js`를 지정하면 같은 시작 탄약 조건으로 15종의 빈 총/잔탄 장전을 비교한다. 실제 상태 기계에서 빈 총 시간만 약 35% 증가하고 잔탄 시간은 같은 것을 확인했다(1ms 간격 측정 오차 허용).
- 실제 게임 메뉴·훈련장 진입, 6종 빈 총 장전, 15종 실제 사격 경로의 오디오 ID 전달, 무기 교체 시 동작 취소 확인.

자동 렌더 검사는 파형·음량·라우팅과 재생 상태의 회귀를 확인한다. 모든 청취 환경에서의 주관적 실사감을 보증하는 검사는 아니다.
