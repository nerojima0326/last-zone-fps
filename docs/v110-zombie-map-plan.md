# v110 백야 검역단지 전용 맵

v109는 기존 섬의 지형·건물·충돌·미니맵을 그대로 쓰고 좀비 소품과 목표를 추가했다. 이번에는 좀비 선택 시 전용 월드를 장착하고 일반 섬의 렌더 객체와 충돌 자료를 분리한다. 일반 모드로 돌아오면 같은 섬 객체·충돌·미니맵·조명을 복원한다.

배경은 눈 덮인 폐쇄 군사 연구단지다. 녹지·해변·주택 대신 높은 콘크리트 외벽, 검역 게이트, 의무 보급동, 배관·저장 탱크, 배수로 철교, 연구동 중정과 남측 헬기장을 만든다. 차가운 새벽빛과 붉은 경보, 제설된 검은 도로와 눈을 대비한다.

목표 동선: 검역 정문 → 의무 보급동 → 두 연료 저장소·발전기 → 배수로 철교 → 통신 중정·차단자 → 남측 헬기장.

1. 섬과 독립된 지형·건물·충돌·미니맵·미션 좌표 및 저장 공간을 연결한다.
2. Blender 원본 제작 건축 모듈·설비를 meshopt로 압축하고 전용 배치·조명·눈 효과를 적용한다.
3. 목표 경로·차량 돌파·탑 등반·헬기 접근 공간을 확인한다. 길찾기 캐시는 새 맵 전용으로 굽는다.
4. 일반 복귀·모바일·전체 미션과 관련 회귀 검사를 실행한다. 실제 화면과 큰 산출물은 저장소 밖에 둔다.
5. 검사 결과를 기록하고 마지막에 BUILD와 version.txt를 110으로 올린다.

새 맵 자원은 좀비 선택 시에만 받는다. 기존 섬과 v109 검증 자료·저장 데이터는 삭제하지 않는다. 실제 하드웨어 GPU가 없는 환경의 FPS는 소프트웨어 렌더러 관측값으로 구분한다.
