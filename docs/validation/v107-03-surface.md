# v107 AR-7 표면 법선 복구

실제 훈련장에서 활성화된 모델은 `assets/models/viewmodels/m4.glb`의 `M4_D` 재질이다. `gunmodels.js`의 FBX 재질은 이 1인칭 화면의 재질이 아니다. 실제 금속도는 0.38, 거칠기는 0.5였다.

| 의심 원인 | 확인 결과 |
|---|---|
| meshopt 법선 양자화 손상 | 디코딩 직후 23,898개 모두 정상. 길이 범위 0.994747~1.005195. 원본 압축 파일을 바꿀 필요가 없다. |
| 접선·노멀맵 방향 | 노멀맵 제거 또는 MikkTSpace 접선 생성 대조에서도 깨진 삼각형이 남았다. |
| 밉맵·비등방성 필터 | 이미 밉맵·LinearMipmapLinearFilter·16배 비등방성 필터를 사용했다. 최대 필터 대조에서도 남았다. |
| 금속도·환경 반사 | 실제 금속도는 1이 아니었다. 금속도와 환경 반사를 0으로 해도 깨진 면이 남았다. |
| 가늠자 분리 시 속성 복사 | 실제 원인. 정점당 4바이트(법선 3+패딩 1)를 3바이트씩 복사했다. 본체 법선 9,960개가 잘못되고 1,546개가 0벡터가 됐다. |

`splitRearSight`가 인터리브 속성의 stride와 offset을 지키도록 수정했다. 교체 총기의 가늠자 분리 코드에도 같은 오류가 있어 함께 보정했다. 재질·조준점·원본 GLB는 유지했다.

- 원본 위치·법선·UV 비교: 수정 전 23,628개 불일치 → 수정 후 0개. 본체+가늠자 23,898개 전부 원본과 일치.
- 실제 표시 메시 전체 30정: 수정 전 AR-7에서만 비정상 법선 검출, 수정 후 전부 0개. 일부 총기의 원래 각진 저폴리곤 실루엣과 이 데이터 손상은 구분했다.
- `check-weapon-surface`, `check-render-clarity`, `check-weapon-catalog`, `check-aim` 통과.
- 동일 훈련장·카메라·100% 렌더 해상도에서 1280×720 및 1920×1080 전후 원본을 촬영했다. `/workspace/artifacts/v107/03-surface/{before,after}`에 보관하고 Git에는 추가하지 않았다.
