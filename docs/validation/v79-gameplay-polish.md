# v79 — 기존 요소 품질 개선

기준: v78 `b5b7241`, 작업 브랜치 `feat/gameplay-polish-v79`.

## 발소리와 보행

- Kenney **Impact Sounds**, CC0 1.0의 발소리·접촉음 25개를 포함했습니다. 원본 파일 합계는 176,655바이트입니다. 파일·라이선스·원본 해시와 고정 미러 커밋은 [출처](../../assets/audio/footsteps/CREDITS.md)에 있습니다. 추가 플러그인 코드는 사용하지 않습니다.
- 지형에 이미 칠해진 흙·모래·바위·포장 가중치를 읽어 풀, 흙, 모래, 자갈, 아스팔트, 콘크리트를 구분합니다. 나무·금속 충돌면도 해당 접촉음을 사용합니다.
- 풀·콘크리트·나무에는 대응 샘플, 흙·모래·자갈에는 문서에 기록한 샘플과 필터·재생 속도 조합을 사용합니다. 물은 기존 합성 물소리를 유지합니다. 모든 바닥 종류를 각각 새로 녹음했다고 주장하지 않습니다.
- 플레이어와 봇 모두 실제 위치 변화로 보행 위상과 좌우 접촉을 계산합니다. 벽을 밀거나 멈추면 발소리와 보행 위상이 진행되지 않습니다. 속도·앉기·달리기에 맞춰 보폭이 달라집니다.
- 샘플은 월드 로딩과 동시에 미리 받으며 메뉴 진입을 기다리게 하지 않습니다. 첫 사용 시 오디오를 해석하고 이후에는 공유합니다. 누락·해석 실패 시 기존 합성음을 사용합니다. 환경음 음량과 음소거는 대체음에도 적용합니다.
- 동시에 추적하는 발소리는 20개로 제한하고 먼 소리는 생략합니다. 정리 시 남은 발소리도 중단합니다.

## 캐릭터 움직임

- 자세·골반·관절을 프레임 시간에 따라 부드럽게 연결합니다. 실제 이동 거리의 보행 위상을 모델과 공유하고, 지지하는 발은 월드 좌표에 고정합니다. 멈춘 뒤에는 발을 안정된 위치로 복귀시킵니다.
- 30m 안쪽의 접지한 캐릭터에 발 IK를 적용합니다. 발별 지면 질의는 최대 초당 12회이며, 멀리 있는 캐릭터·점프·사망·엎드린 자세에서는 접지 IK를 사용하지 않습니다.
- 실제 군인 모델의 다리 길이, 발목에서 신발 밑면까지의 높이, 경사면 법선을 사용합니다. 기본 골격의 길이를 실제 모델에 그대로 적용하지 않습니다.
- 엎드린 자세에서 다리·몸통이 바닥으로 내려가던 모양을 보정하고 총의 높이를 조정했습니다. 3인칭 손 IK는 움직이는 총 거치대를 따라갑니다. 1인칭 조준 기준점이나 피해·탄도 계산은 변경하지 않았습니다.
- 실제 모델 4종의 걷기·멈춤·앉기 검사에서 접지 중 최대 목표 오차는 약 13.1mm, 프레임 간 미끄러짐은 약 7.3mm였습니다. 공중에서 발을 옮기는 구간은 다리 길이 제한에 따라 목표점과 최대 약 38.3mm 차이가 납니다. 모든 자세에서 오차가 0이라고 주장하지 않습니다.

## 총기 재질·조명과 화면

- 총기 30종의 재질을 금속, 도장, 플라스틱, 목재, 장갑·천으로 분류해 거칠기·금속도·환경 반사 강도를 조정합니다. 원본 텍스처 색은 유지하고 유리·조준점·발광 효과는 보존합니다. 실제 1인칭 팩과 뒤늦게 생성되는 모델에도 적용합니다.
- 1인칭에는 그림자를 추가하지 않는 약한 보조광을 쓰고, 실내 주변광이 지나치게 낮아지지 않도록 조정합니다. 밤의 보조광은 낮보다 약합니다.
- 기본 필름 입자는 기존 강도의 15%, 렌즈 색 번짐은 0%, 가장자리 어두움은 45%로 낮췄습니다. 대비·녹색 보정도 완화하고 작은 그림자 보정을 기존 색보정 패스에 합쳤습니다. 추가 화면 전체 후처리 패스는 없습니다.
- 네 가지 효과 강도를 설정에서 조절·저장할 수 있습니다. 이전 설정에 새 항목이 없으면 기본값을 사용하고 기존 감도·키 설정은 유지합니다.

## 봇과 거리별 모델

- 좌우 이동 결정을 더 오래 유지하고 실제 이동량을 완만하게 바꿉니다. 좁은 곳에서 양쪽이 막히면 멈추며 매 프레임 방향을 뒤집지 않습니다. 방향 탐색은 일정 간격이나 큰 회전 때만 수행합니다.
- 장전 중 도달 가능한 엄폐 지점을 유지합니다. 도착·이탈 반경을 다르게 두어 반복적인 앉기·이동을 줄이고, 막힌 목표나 바뀐 상대는 다시 평가합니다. 난이도별 반응 시간·명중률·탄도는 유지합니다.
- 총기는 11–13m, 26–30m 전환 구간에서 인접 모델이 화면 픽셀을 나눠 그립니다. 두 모델의 커버리지 합은 1이며 시간에 따라 무작위 패턴을 바꾸지 않습니다. 확대 조준의 거리 보정도 유지합니다.
- 나무는 상세 모델과 사진판을 반경 ±6m에서 연결합니다. 밀도에 따른 반경 변화도 완만하게 하고, 화면 가장자리에서는 수관 폭을 반영합니다. MSAA를 지원하고 사용하는 중간·높음 품질에서 잎의 알파 커버리지를 적용합니다.
- 전환 재질은 원본·단계별로 공유합니다. 같은 총의 복사본마다 재질을 새로 만들지 않습니다. 전환 구간에서는 추가 모델을 그리는 비용이 있으며, 총기 그림자는 대표 단계 하나만 그립니다.

## 검증과 비교

11개 검사 모두 통과했습니다. 실제 마우스 조작으로 10m·50m·100m 표적 명중, 총기 30종의 조준·반동·손·장전·사운드, 도감·모바일·전투·재시작을 확인했습니다. 새 통합 검사는 설정을 저장한 뒤 페이지를 다시 열어 복원되는 것까지 확인합니다. 브라우저 코드·셰이더 오류는 없었습니다.

같은 훈련장 장면의 5회 중앙값은 다음과 같습니다. GPU 타이밍을 동기화하는 소프트웨어 렌더러 검사이므로 실제 플레이 FPS로 환산하지 않습니다.
