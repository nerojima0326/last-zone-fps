# v75 새 발사음 검증

[15종 새 총성](v75-new-reports.mp3) · [이전/새 총성 비교](v75-reports-comparison.mp3) · [검사 요약](v75-audio-checks.json)

검증 범위:

- 새 생성기의 15종 × 발사 변형 4개 + 근거리·원거리 각 1개 = 90개 파형이 모두 다르며, 같은 입력은 동일한 결과를 만듭니다. 기존 발사음 파형 입력은 0개입니다.
- 44.1/48kHz에서 유한한 PCM, 시작 지연, 헤드룸, 발사 변형 간 음량 편차 및 재생 길이를 검사했습니다.
- 실제 게임에서 31개 뱅크의 디코딩·해시, 15종의 단발·연사·장전, 지원되는 13종의 소음기 믹스를 검사했습니다.
- 다운로드 뱅크를 모두 제거한 상태에서도 15종 모두 새 생성기로 발사하며, 구버전 매니페스트가 있어도 새 발사음으로 재생됩니다.
- 스테레오 시작점, 오디오 큐 격리, 음량 0, 대체 재생 음량 0, 재생 종료 후 노드 정리를 검사했습니다.
- 새 발사음 뱅크 15개와 매니페스트의 재생성 결과가 바이트 단위로 동일합니다. 기존 조작음 뱅크 15개도 동일한 해시를 유지합니다.

비교 JSON의 스펙트럼 거리는 발사 시작 뒤 200ms의 8개 주파수 대역 비율 차이이며 음량 크기를 제외합니다. 파형 상관은 시작점 주변 ±8ms의 최대 정규화 상관입니다. 수치가 주관적인 소리의 선호도를 판정하지는 않습니다.

재현:

```bash
node tools/build-original-weapon-audio.cjs /tmp/original-reports
node tools/check-original-weapon-audio.cjs
REPORT=/tmp/weapon-audio.json RENDER_AUDIO=/tmp/v75-wavs node tools/check-weapon-audio.cjs
# v74 작업 트리에서 같은 방식으로 /tmp/v74-wavs를 만든 뒤 비교
python tools/compare-weapon-reports.py /tmp/v74-wavs /tmp/v75-wavs /tmp/audio-comparison
```

총 12개 검사 명령을 통과했습니다. 훈련장 대체 에셋 검사는 첫 실행의 재입장 대기에서 시간 초과가 발생했으며, 코드를 바꾸지 않고 같은 명령을 재실행해 통과했습니다.
