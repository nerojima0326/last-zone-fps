# v73 손·총 자세 검증

[전후 비교](v73-hand-comparison.jpg) · [15종 전체 자세](v73-all-weapon-holds.jpg) · [검사 요약](v73-hand-checks.json)

- 실제 게임의 15종 모두 지향·조준·보행·질주·사격을 30/60/144 FPS에서 검사: 225조건.
- 잔탄·빈 총 장전을 60 FPS에서 연속 재생하고, 시작·일반 탄 삽입·마지막 탄 삽입·종료 구간을 검사: 216조건. 실제 장전 방식에 맞는 탄 수와 약실 장전 플래그를 사용합니다.
- 장전 종료 후 복귀 및 같은 자세를 100회 적용하는 검사: 30조건. 누적 오차 없음.
- 총과 손을 함께 회전·이동해도 표면 교차 측정이 같아야 하는 검사: 15조건.
- 보정을 끈 원본에서도 같은 지향·조준·이동·질주·사격 검사를 실행해 그립 미끄러짐과 장갑 간섭을 검출했습니다.

검사는 보정 목표점 대신 변형된 손 메시와 보이는 총의 삼각형을 사용합니다. 열린 모델에 적용할 수 없는 광선 홀짝 기반 내부 판정은 사용하지 않습니다. 수치 안정성을 위해 같은 총의 강체 좌표계에서 삼각형을 비교합니다. 장갑 접촉부의 기존 겹침을 허용하는 회귀 한계는 기본 자세에서 손바닥 6.5mm·손가락 11mm, 장전 중 손바닥 10mm·손가락 15mm입니다. 표면 교차 지표이며 모든 접촉이 사라졌다는 판정은 아닙니다.

재현:

```bash
# NODE_PATH에 playwright@1.62.1, three@0.160.0, three-mesh-bvh@0.7.8 필요
# 필요하면 CHROME_BIN과 THREE_DIR 지정
REPORT=/tmp/hand-poses.json node tools/check-hand-poses.cjs
REPORT=/tmp/aim.json node tools/check-aim.cjs
```

CI에도 손 검사를 추가했습니다. 기존 모델 가져오기·훈련장·대체 모델·전투·장전·팔 간섭·오디오를 포함한 10개 검사도 통과했으며, 마지막 손 보정 후에는 손 검사와 조준·탄도·반동 검사를 다시 통과했습니다.
