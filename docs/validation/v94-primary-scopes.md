# v94 1번 슬롯의 8배율 장착 제한

v93 스코프 모델 수정 `d210227a72d96aa37ef1402f16d7ac9e34035147` 위에 추가했습니다.

이미 달린 비호환 조준경은 지급·줍기·무기 표시·부착물 창·사망 상자 처리에서 가방으로 돌려줍니다. 재검사 시 수량이 다시 증가하지 않으며, 기존 8배율을 든 채 총기를 교체해도 수량을 보존합니다. 표시 경로도 호환 목록을 확인하므로 이전 상태에 8배율이 남아 있더라도 8배율로 조준하지 않습니다.
