# v107 장전 손 관통

기준 커밋: b375107 (v106). `THREE_DIR`를 Three.js 0.160.0 설치 경로로 지정했다.

1. 수정 전 `node tools/check-clearance.cjs`: 180조합·32,334프레임, 실패 14건. MS56 전술 장전 144FPS에서 최대 17.8395mm.
2. 원인: v99의 플랫폼별 장전 방식·탄창 유지 시간 변경 이후, 탄창 삽입 뒤 지지 자세로 바뀌는 약 70% 지점에 측면 탈출 경로가 없었다. 손바닥 방향이 바뀌면서 손목·소매가 리시버를 통과했다. 원본 손 이동 또는 손목 회전을 각각 꺼도 전술 장전 실패가 남았다. 단순히 원본 모션을 제거하는 것으로 해결되지 않았다.
3. 여섯 총기의 탄창 접촉 사건을 보존하고 복귀 전에 왼쪽 아래 경유점을 추가했다. SR25의 빈 총 장전에서는 탄창을 떨어뜨린 뒤 탄입대로 향하는 자유 손에만 바깥쪽 곡선을 더했다. 실제 접촉 사건에서 추가 변위는 0이다.
4. 수정 후 같은 검사: 실패 0건, 작동 최대 0mm, 복귀 최대 9.9738mm. 기준은 작동 3mm·복귀 10mm 그대로다.

실제 훈련장 전후 화면은 `SHOTS=<외부 폴더> node tools/capture-reload-clearance.cjs`로 같은 1280×720 화면·위치·장전 진행률에서 재현한다. 이번 원본은 `/workspace/artifacts/v107/01-clearance/{before,after}`에 보관하며 Git에 추가하지 않는다. 기존 손 메시와 장전의 탄약·부품 접촉 로직은 유지한다.
