# v74 총성·장전음 검증

[게임 믹스 미리듣기](v74-weapon-audio.mp3) · [검사 요약](v74-audio-checks.json)

미리듣기는 게임과 같은 녹음·재생 게인·압축기로 렌더링했습니다. 각 구간은 총성 뒤에 빈 총 장전이 이어집니다. G-18은 연사 예시입니다.

| 총기 | 구간 |
|---|---|
| AR7 | 0.00–5.95초 |
| KA47 | 5.95–10.76초 |
| S12 | 10.76–17.65초 |
| G18 | 17.65–22.06초 |
| DE7 | 22.06–26.06초 |

- 31개 MP3 뱅크 디코딩 및 캐시 해시 검사.
- 실제 게임의 가져온 총기 애니메이션 팩을 모두 불러온 상태에서 15종 × 잔탄/빈 총 = 30개 장전의 소리 이벤트를 수집하고 렌더링.
- 15종 각각 단발·연사·장전, 지원되는 13종의 소음기 믹스 검사. 재생되는 발사 테이크를 고정해 소음기 전후 파열음을 비교.
- 연사 출력의 피크가 0.98 아래인지 확인하고, 앞 발의 잔향/음성 수 제한과 종료 후 노드 해제를 검사.
- 오른쪽 채널의 파열음이 40ms 먼저인 합성 입력으로 스테레오 시작점 보존 검사.
- 디코더 보정으로 시작점이 늦어져도 다음 오디오 큐가 새어 나오지 않는지 검사.
- 모든 총기의 사격·장전 음량 0, 명시적 게인 0, 샘플이 없을 때의 합성 사운드 음량 0 검사.
- 재생성한 31개 MP3와 매니페스트가 배포 파일과 바이트 단위로 동일함을 확인.

재현:

```bash
# 기존 브라우저 테스트와 동일하게 playwright, three 및 Chromium 사용
REPORT=/tmp/weapon-audio.json node tools/check-weapon-audio.cjs
# 게임 믹스를 WAV로 저장하려면 RENDER_AUDIO=/tmp/weapon-wavs 추가
python tools/remaster-weapon-audio.py /tmp/rebuilt-weapon-audio
```

오디오 검사와 함께 모델 가져오기, 조준·탄도·반동, 훈련장·대체 에셋, 손 자세 441조건, 전투, 장전·팔 간섭 검사를 통과했습니다. 전체 11개 검사 명령의 결과는 검사 요약에 있습니다.
