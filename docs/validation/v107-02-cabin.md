# v107 운전석 몸통 가림

기준 b375107의 IZH에서 아래로 보는 시점(-0.42rad)을 재현했다. 머리 뼈만 축소한 상태에서는 카메라 앞에 남은 목·몸통의 안쪽 삼각형이 화면 하단을 덮었다. 포터의 눈 위치에서는 덜 드러나지만 같은 몸 메시가 렌더링되고 있었다.

내부 시점 전용 지오메트리는 팔 뼈와 그 자식에 속한 삼각형만 보존한다. 뼈 변환과 운전대 IK는 유지한다. 외부 시점·하차에서 원본 지오메트리를 복원하며, 모델 제거 시 전용 자원도 해제한다. 네 차종에 같은 규칙을 적용했다.

- `check-vehicle-cabin.cjs`: 4종 F/V·경사·하차·메뉴 복귀, 5리그×3조향 자세 통과. 내부 팔 메시·외부 전체 몸 복원 검사 추가.
- `capture-vehicle-cabins.cjs`: 4종 내외부·IZH 손 확대·실제 훈련장 촬영 통과. 반복 탑승 자원 증가: 지오메트리 0, 텍스처 0.
- 동일한 ranger 캐릭터로 기준 커밋/수정 후를 비교했다. `/workspace/artifacts/v107/02-cabin/{before,after}`에 원본을 보관하고 저장소에는 넣지 않았다.

재현: `BASELINE=b375107 SHOTS=<이전 폴더> node tools/capture-vehicle-cabins.cjs`, 수정 후에는 `BASELINE`을 생략한다.
