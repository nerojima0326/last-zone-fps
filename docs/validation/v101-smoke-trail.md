# v101 연막탄의 비행 궤적 연기와 착지 분사

기준 버전: v100 `23341e70be77f0fb0eee902cbd88f98b7140befc`.

## 확인한 원인과 변경

v98 이후 코드는 공중 대형 연막을 막기 위해 퓨즈 만료와 지면 지지를 함께 기다렸습니다. 비행 중에는 연기 입자를 만드는 별도 경로가 없었습니다. 따라서 위로 던지면 연막 없이 날아가고, 짧게 던져도 착지 후 퓨즈가 끝날 때까지 기다렸습니다.

- 연막탄의 실제 이전·현재 위치 사이에 연기를 배치합니다. 상승·정점·하강의 포물선을 따르며, 낮은 FPS에서도 프레임 사이를 채웁니다. 실제 화면에서 점처럼 보이던 초기 입자 간격과 크기도 조정했습니다.
- 비행 꼬리는 약 1.35~1.65초 동안 작게 퍼졌다가 사라집니다. 별도의 대형 연막이나 시야 차단 판정을 공중에 만들지 않습니다.
- 지면·지붕의 위쪽 표면 또는 수면에 처음 닿으면 퓨즈 대기 없이 본 연막을 분사합니다. 벽·천장 충돌에서는 전환하지 않습니다. 비행 꼬리의 새 입자는 전환 시 멈추고 남은 입자만 자연스럽게 사라집니다.
- 본 연막의 확산 반경·지속 시간·시야 차단은 유지하며, 연막 중심은 굴러가는 연막탄을 따릅니다. 수류탄·섬광탄의 퓨즈와 화염병의 충돌 점화는 유지합니다.
- 기존 `FX.norm`의 인스턴스 입자·텍스처·재사용 풀을 씁니다. 별도 메시나 텍스처를 추가하지 않았습니다. 품질 변경·먼 거리·한 번에 많은 투척에서도 밀린 입자를 몰아서 생성하지 않습니다.

## 품질별 생성 한도

| 품질 | 궤적 입자 간격 | 전체 비행 꼬리 생성 상한 | 24개 동시 투척, 1.25초간 실제 생성 |
|---|---:|---:|---:|
| 최저 | 0.42m | 초당 96개 | 116개 |
| 낮음 | 0.32m | 초당 128개 | 155개 |
| 중간 | 0.26m | 초당 192개 | 236개 |
| 높음 | 0.22m | 초당 240개 | 300개 |

위 수치는 모든 연막탄의 비행 꼬리에 공유하는 예산입니다. GPU 성능이나 실제 휴대폰 FPS를 측정한 수치가 아닙니다.

## 검증

Chromium / Three.js r160 / SwiftShader 환경입니다.

- [비행·착지·예산 검사](v101/smoke-trail-checks.json): 4단계 품질 × 30/60/144FPS × 위/짧은 투척의 24개 조합을 통과했습니다. 실제 입자 출생 좌표와 이동 궤적의 일치, 상승·하강 구간의 연기, 착지 위치, 시야 차단, 착지 이후 꼬리 생성 중지를 검사합니다.
- 지붕·수면·긴 퓨즈의 짧은 투척 3개와 벽·천장 충돌 2개를 확인했습니다. 벽·천장에서는 본 연막이 생기지 않고 이후 착지에서 분사합니다.
- 24개 동시 투척을 각 품질에서 검사했습니다. 생성 예산과 기존 입자 지오메트리·텍스처 재사용을 확인했고, 초기화 후 입자는 모두 사라졌습니다. 연막탄·본 연막의 수명 종료도 확인했습니다.
- [기존 투척 검사](v101/throwable-checks.json): 투척 48개 조합, 안전핀·쿠킹·취소·복귀·실제 장갑 접촉과 바닥·지붕·수면 연막 검사를 통과했습니다.
- [v100 재현 기록](v101/baseline-checks.json)은 같은 비행 연기 검사에서 입자가 0개라 실패합니다. 변경 전에는 비행 꼬리가 없었음을 확인하는 용도로 실행했습니다.
- [영상 형식](v101/video.json)과 [브라우저 재생·탐색](v101/playback.json)을 확인했습니다. [변경 전](v101/before-video.json)·[변경 후](v101/after-video.json)의 실제 탄 위치·입자 생성·연막 시작 시각을 기록했고 MP4 전체 디코딩도 통과했습니다.

```bash
REPORT=/tmp/smoke-trail.json node tools/check-smoke-trail.cjs
THROW_CHECKS=/tmp/throwable-checks node tools/check-throwable-motion.cjs
SMOKE_SHOTS=/tmp/smoke-video node tools/capture-smoke-trail.cjs before
SMOKE_SHOTS=/tmp/smoke-video node tools/capture-smoke-trail.cjs after
SMOKE_SHOTS=/tmp/smoke-video node tools/capture-smoke-trail.cjs encode
```

기존 브라우저 검사와 같이 `NODE_PATH`, `THREE_DIR`, `CHROME_BIN`을 설정합니다. 영상 인코딩에는 FFmpeg와 Noto Sans CJK 폰트를 사용합니다.
