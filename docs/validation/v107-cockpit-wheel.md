# v107 핸들 모델

기존 핸들은 동일한 토러스·원통·상자 3개였다. 차종별 림 굵기/크기, 둥근 패드, 테두리까지 이어지는 살, 12시 표식을 절차적 지오메트리로 만들었다. IZH는 2개 살과 크롬 경적 링을 쓴다. 외부 모델을 다운로드하지 않았다.

| 차종 | 삼각형 | 손바닥 반지름 | 접촉점과 림 표면 간격(최대) |
| --- | ---: | ---: | ---: |
| porter | 1,376 | 235mm | 0.39mm |
| e2200 | 1,376 | 219mm | 0.81mm |
| izh | 1,828 | 219mm | 0.45mm |
| 대체 | 1,376 | 219mm | 0.74mm |

`check-cabin-model.cjs` 통과: 2천 삼각형 이하, 한 메시, 공유 템플릿, 손 접촉점에서 림으로 쏜 광선의 표면 간격 3mm 이하. `check-vehicle-cabin.cjs`도 통과했다(4차종, 캐릭터 5종×조향 3각도, 내부 팔·외부 몸 복원, 경사·하차).

실제 WebGL 화면에서 IZH 경적 링·표식·양손과 트럭 림을 확인했다. 기존 촬영 도구의 내외부·훈련장 캡처 및 반복 탑승 검사도 통과했고, 8회 반복 뒤 지오메트리/텍스처 증가가 각각 0이었다. 상세 결과와 이미지는 저장소 밖 `/workspace/artifacts/v107-cockpit/02-wheel-*`에 보관했다.
