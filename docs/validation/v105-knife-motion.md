# v105 칼별 모션과 발리송 전개

발리송을 꺼내면 닫힌 칼날과 자유 손잡이가 순서대로 펼쳐지고, 마지막에 중지·약지·새끼손가락이 손잡이를 다시 잡습니다. 검사는 접기→닫힘 확인→재전개→날 양면 확인으로 이어집니다. 공격은 펼친 상태에서 실행하며 검사 도중 공격을 누르면 현재 자세에서 전개를 마친 뒤 벱니다.

[칼 6종 전후 비교 영상](v105/knife-motion-comparison.mp4) · [발리송 비교 화면](v105/knife-motion-comparison.jpg) · [검증 수치](v105/checks.json)

## 변경

- 기존 v104는 발리송 관절을 모든 동작에서 0으로 고정했습니다. v105는 움직이지 않는 안전 핀 아래에 칼날 탱을 두고, 자유 손잡이 핀은 탱을 따라 움직이도록 구성합니다. 두 핀의 간격은 22mm입니다.
- 자체 제작한 채널 손잡이·칼날·래치 모델을 번들 GLB로 교체했습니다. 접힌 칼날이 들어갈 홈, 끝이 둥근 손잡이와 손가락이 닿는 슬롯을 포함합니다. 파일은 101,312바이트, 3,064삼각형이며 텍스처를 추가하지 않았습니다.
- 검은 전술 장갑·녹색 소매를 유지합니다. 엄지와 검지는 안전 손잡이를 지지하고 나머지 손가락만 전개 중 벌어집니다. 장갑의 실제 손 뼈 변환을 칼에 적용하므로 팔꿈치·손목 회전 중 그립이 미끄러지지 않습니다.
- 칼 6종에 꺼내기 6개·공격 12개·검사 6개를 다시 작성했습니다. 단검은 정면·올려 찌르기, 전투 나이프는 두 방향 사선 베기, 카람빗은 짧은 갈고리 베기, 쿠나이는 빠른 사선 찌르기, 마체테는 수직·넓은 수평 베기를 사용합니다.
- 공격 피해량·사거리·공격 주기·타격 시점 43%와 기존 키 바인딩을 유지합니다. 모델을 불러오지 못해도 채널과 슬롯이 있는 대체 모델로 같은 전개를 재생합니다. 3인칭 손가락은 검사 종료·무기 전환·차량 탑승 때 기존 자세로 복귀합니다.

## 참고 자료의 범위

Google 검색과 YouTube는 이 환경의 프록시에서 CONNECT 403으로 차단됐습니다. GitHub의 저장소 검색과 원본 소스 열람은 성공했습니다.

[GambelStrike2의 고정 커밋 뷰모델](https://github.com/erqf1/GambelStrike2/blob/ccde7d5e021cb80f3e2a6889b145f6d6fe59725c/js/viewmodel.js)에서 발리송의 칼날·자유 손잡이 분리, 칼날 전개 후 손잡이 회수, 재그립 순서를 확인했습니다. 해당 프로젝트의 코드나 키프레임을 복사하지 않고 LAST ZONE의 손 리그에 맞는 별도 곡선을 작성했습니다. 상용 게임의 모션 파일을 반입하거나 YouTube 영상을 시청·추출한 결과가 아닙니다. 모델과 기존 자료의 라이선스는 [출처 기록](../../assets/models/knives/CREDITS.md)에 보존했습니다.

## 확인 방법

비교 영상은 동일한 실제 게임 손 리그와 뷰모델 카메라로 v104와 v105를 각각 30FPS 렌더링한 결과입니다. 각 칼의 꺼내기·공격 두 방향·검사를 차례로 재생합니다. 짧은 쪽은 마지막 자세에서 기다린 뒤 다음 동작을 함께 시작합니다. 배경을 단색으로 두어 손과 칼의 접점을 보기 쉽게 했습니다.

검증은 Chromium과 소프트웨어 WebGL에서 수행했습니다. 모바일 검사는 터치 UI 입력 경로의 브라우저 자동화이며 실제 Galaxy S24 FE의 FPS 측정이 아닙니다.

```sh
source /workspace/.last-zone-fps-env/env.sh
node tools/check-knife-motions.cjs
node tools/check-knives.cjs
KNIFE_FALLBACK=1 node tools/check-knife-motions.cjs
node tools/check-knife-touch.cjs
```

- 실제 스키닝된 장갑·칼 삼각형의 교차 검사: 정상·대체 모델 각각 1,150개 자세. 기존 기준인 2mm 미만을 적용합니다.
- 정상 모델의 최대 교차 깊이: 발리송 1.950mm, 카람빗 0.712mm, 나머지 네 칼 0mm. 대체 발리송은 1.412mm입니다.
- 모델의 기본 길이·대기 자세 차이를 제외한 손의 상대 궤적 96쌍을 비교해 각 칼·공격 방향의 차이를 확인합니다.
- 30·60·144FPS에서 72개 동작의 실제 칼끝 연속성·손목 각도·복귀를 검사합니다. 발리송은 움직이는 칼날 노드에서 칼끝을 추적합니다.
- 검사 중 공격 전환 6종, 추가 발리송 검사 중단 지점 10곳을 확인했습니다. 추가 지점의 최대 시작 위치 차이는 0.057mm이며 타격 시점에는 두 관절 모두 펼쳐집니다.
- 실제 공격의 한 번 타격·두 방향 교대·아군 보호·벽 가림·사거리·무기 전환/사망 후 취소·훈련 표적·키 재지정·3인칭 그립과 복귀를 검사합니다. 손잡이의 화면 가로 좌표는 정규화 절댓값 0.801 이하입니다.

모델 재현은 기존 `tools/knives/build.cjs` 이후 `node tools/knives/build-balisong.cjs`를 실행합니다. 새 모델 빌더를 두 번 실행해 같은 SHA-256을 생성하는 것도 확인했습니다.

```sh
KNIFE_SHOTS=/tmp/lz-after KNIFE_VIDEO=1 node tools/capture-knife-motions.cjs
python3 tools/compare-knife-motions.py /tmp/lz-before /tmp/lz-after /tmp/knife-motion-comparison.mp4
```
