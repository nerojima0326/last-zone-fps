# v108 수정 검증

1. 상공 시야: 실제 최저/낮음 fog 배율 1.45/1.2와 far 750/1100을 확인했다. 1km 안개 투과율이 최저 약 0.01%라 섬이 흰색으로 사라졌다. 상공 목표 밀도 0.00045, 높이 15~160m의 완만한 복귀를 적용했다. 기존 건물 대역·성긴 지형만 원거리에서 보이고 상세 LOD·풀 제한은 유지한다. 4품질×4날씨×4상태 검사 64개와 강하·비행기·품질 검사 3종이 통과했다. 동일 1280×720의 수송기/250m 낙하 전후 8쌍을 저장소 밖 `/workspace/artifacts/v108`에 저장했다.

2. HUD: 강하 중에도 무기 패널이 남고, 1100px 이하 나침반의 64vw 규칙이 생존 상자로 침범하는 것을 확인했다. 강하 상태에만 무기 패널을 숨겨 착지 시 복원하고, 안내 폭·줄바꿈과 무기 칸 말줄임을 적용했다. 실제 우측 상자 크기를 관찰해 나침반 폭을 정한다. 4해상도×4상태의 16개 배치 검사와 조준선·세션·모바일 검사 3종이 통과했다. 전후 원본은 외부 `before-air-hud`/`after-air-hud` 폴더에 보관했다.

3. 운전 팔: 실제 조향각은 최대 약 41도라 60도 이후 처리로는 해결되지 않았다. 손이 10시/2시에서 중앙 위로 회전해 Ranger 소매가 게이지의 3.38~16.58%를 가렸다. 기본 손 위치를 9시/3시로 낮추고 회전량에 따라 림을 미끄러지게 했다. 굵기가 변하는 림 표면도 접촉 반지름에 반영했다. 4차종 A/D 실제 팔 삼각형 마스크에서 가림 0%, 조향·손 접촉 및 기존 운전석·계기판·모델 검사 3종 통과. 동일 장소의 4종 정지/A/D와 야간 원본은 외부 `before-cabins`/`after-steering`에 보관했다.

4. 차종별 계기판: 공통 두 원형 구조를 포터(큰 속도계+연료·수온), E2200(두 원형+중앙 표시등), IZH(고전 속도계+바늘 연료계), 대체 차량으로 구분했다. 캔버스는 차종별 한 번만 그리며 미니 바늘은 인스턴스 한 호출로 합친다. 연료 잔량과 표시용 수온 상태를 물리에 추가했다. PC/844×390에서 계기판 숫자 가림 0, 최대 6호출로 기존 대비 증가 0, 새 광원 0, 반복 탑승 자원 증가 0을 확인했다. 큰 속도계/RPM 문자는 8px 이상, 보조 문자는 4px 이상 투영 기준이며 실제 화면도 확인했다. 정지·주행·밤 전후 원본은 외부 `after-steering`/`after-dashboard`에 있다.

5. 차종 성능: 공용 속도·가속·조향 상수와 별개로 축간거리는 이미 달랐다. 차종별 표를 물리·봇 순항·체력·충돌 피해·계기판 최대 눈금에 연결했다. 실제 30/60/144Hz 측정표는 `v108-vehicle-tuning.md`에 기록했다.

8. 자동 품질: 기존 코드도 1초 넘는 프레임은 무시했지만 판 시작·착지·탑승 보호가 없고 0.5초 단위 하향 누적에 취약했다. 판 시작 6초, 착지·탑승 3초를 제외한다. 단발 긴 작업은 측정 구간을 비우고, 지속 저성능은 4~7초 누적 뒤 하향한다. 회복은 상한 해상도의 90% 이상에서 12초 건강한 상태를 확인한다. 다음 판은 저장된 단계보다 한 단계 위를 임시 시험하고 10초 건강할 때 저장한다. 저장값이 GPU의 회복 상한까지 낮추던 경로도 분리했다. 실제 2초 정지와 지속 부하·다음 판 재시험 검사를 추가했다.
