# v108 실내 장착·검사·미러 후속 수정

기준은 `674ebae`다. 점검에서 E2200 공조 패널 뒤 약 38.3mm, 4종 비상등 표시 뒤 약 32mm의 빈 공간을 확인했다. E2200의 기울어진 원본 대시보드에 맞춰 라디오·공조 공통 받침을 추가하고, 비상등은 라디오 프레임에 붙인 버튼 표면으로 옮겼다. 넓힌 검사에서 발견한 수납함 하단 약 13.6mm의 틈도 뒤쪽 깊이를 늘려 보완했다. 공조·수납함의 앞면 크기와 위치는 유지한다.

정적 메시의 부품 범위와 몸체 범위를 템플릿에 기록한다. 새 검사는 그 좌표를 정답으로 비교하지 않고 실제 정점에서 몸체 경계를 다시 구한 뒤, 주변 원본 차체·실내 표면으로 레이를 쏴 2mm 이하의 연결 틈을 확인한다. 4차종×5부품×9지점 180개가 통과했다. 비상등 인쇄면의 의도한 0.6mm 간격이 최대 양의 틈이며, 나머지는 받침에 겹쳐 고정된다. 공조 패널·표시 형상을 실제로 12cm 이동시킨 8개 경우도 모두 실패로 검출한다.

계기 숫자 검사는 기존 손·핸들에 원본 불투명 차체와 모든 실내 부품을 추가했다. 차체 쪽에 임시 가림막을 만들어 검출도 확인한다. PC·모바일에서 숫자 가림 0, 주요 숫자 8px/보조 숫자 4px 기준, 정지·최대 조향의 팔 가림 0%를 유지한다.

E2200 원본 glTF의 `Mirrors`는 백색·금속도 1·거칠기 0이었다. 미러 재질을 청회색·금속도 0.92·거칠기 0.16·환경 반사 강도 0.45로 조정하고 원본 면에 맞춘 둥근 테두리를 더했다. 기존 환경 반사를 부드럽게 사용하는 방식이며 새 카메라·렌더 패스·텍스처·광원은 없다. 낮 정면 캡처의 동일 내부 표본(115×30px, 모든 채널 225 초과)의 백색 비율은 약 75%→0%다.

실내 부품은 기존 정적 메시와 차종별 템플릿을 재사용한다. 실내 그리기 호출은 최대 6회로 증가가 없고, 반복 탑승 자원 증가도 0이다. 원본 이미지·로그·측정 결과는 저장소 밖 `/workspace/artifacts/v108-cabin-mounts`에 기록한다. 과거 검증 자료와 원본 자산은 변경하지 않았다.

최종 검사는 PC 9종(장착·계기판·핸들 모델·조향·운전석·조작·입력·물리·바퀴)과 모바일 2종(계기판·터치 조향)이 모두 통과했다. 4종의 낮 정면·콘솔 상세·밤 12장과 모바일 정면 4장을 저장소 밖에 촬영했다.
