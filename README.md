# LAST ZONE — 배틀로얄 FPS

Three.js로 만든 브라우저용 3D 배틀로얄 FPS입니다. 설치나 빌드 없이 바로 실행됩니다.

## 칼 6종·꺼내기·공격·자세히 보기 (버전 90)

- 버터플라이 나이프·양날 단검·전투 나이프·카람빗·쿠나이·마체테를 추가했습니다. GitHub에서 배포된 모델을 미터 단위·그립 좌표로 변환해 번들에 넣었습니다.
- **5**로 칼을 꺼내고 다시 누르면 종류가 바뀝니다. **좌클릭**은 휘두르기, **우클릭 또는 T**는 자세히 보기입니다. 훈련장의 **J → 칼 6종**에서도 선택할 수 있습니다. 키 재지정과 터치 조작도 지원합니다.
- 가져온 꺼내기·검사·검 공격 클립을 기존 팔 IK에 맞췄습니다. 버터플라이 손잡이는 별도 관절로 펼쳐지고 접힙니다. 공격은 근거리의 적 한 명에게 한 번 적용되며 벽·아군·무기 전환·사망을 확인합니다.
- 모델 6종의 합계는 약 1.6MB이며, 모든 파일이 게임에 포함되어 있습니다. 누락 시 기본 칼과 동작으로 복귀합니다.

## 비행기 모델 재제작 (버전 89)

- LZ-89 대형 군용 수송기로 외형을 새로 만들었습니다. 폭이 넓은 화물 동체, 볼륨 있는 기수와 조종석 어깨, 후퇴익·윙렛, 네 개의 제트엔진, 높은 T자 꼬리날개를 사용합니다.
- 엔진 흡입구 안에 깊이가 있는 덕트·28엽 회전 팬·중앙 스피너를 넣고 뒤쪽 배기 코어도 모델링했습니다. 강하문은 동체를 실제로 뚫어 안쪽 벽·문틀·발판을 연결했습니다.
- 고정 부품을 재질별로 병합해 기체당 메시 수를 88 → 26개로 줄였습니다. 삼각형 수는 정비 디테일을 포함해 약 4.5만 개입니다.

## 수송기 모델·강하·낙하산 전개 개선 (버전 88)

- 수송기 창·문의 뒤집힌 면을 고치고, 비행 중 바퀴를 접은 외형·6엽 프로펠러·강하 신호등·기체 표식을 적용했습니다.
- 실제 강하문 위치에서 기체 속도를 물려받아 이탈하며, 이탈 자세 → 자유낙하 → 급강하로 부드럽게 움직입니다. 군인 4종과 기본 대체 캐릭터에 함께 적용됩니다.
- 9셀 낙하산이 줄을 펴고 부풀어 오르는 동안 몸이 세워지고 감속합니다. 하네스에서 천까지 연결줄이 이어지며 시점도 전개에 맞춰 넓어집니다.
- 강하 중 **Shift를 누르고 있으면 빠르게 하강**합니다. 자유낙하 약 48 → 82m/s, 낙하산 약 5.2 → 14m/s이며, 키를 놓으면 복귀합니다. 양쪽 Shift·키 재지정·모바일 스틱 끝까지 전진하기를 지원합니다.

[전후 화면·하강 수치·브라우저 검증 기록](docs/validation/v88-airdrop.md)

## 맵 배치·수면·고저차 주행 개선 (버전 87)

- 집을 도로를 향한 필지·골목과 접근로 주변으로 다시 배치하고, 기초가 과도하게 높아지는 경사면을 피합니다. 나무 사이 간격과 도로·건물 주변 여유 공간을 확보합니다.
- 호수·강 수면을 지형 해안선에 맞춰 통합하고, 강 수위가 호수 입출구와 연속으로 이어지게 했습니다. 표시 수면과 수영·탄도·차량의 물 높이 판정을 같은 삼각형 보간으로 맞춥니다.
- 차량은 실제 바퀴 접점에서 지면을 읽고, 지면을 벗어나면 중력으로 낙하합니다. 착지 충격·서스펜션·자세 복귀와 공중 하차를 처리합니다.
- 도로·건물·근거리 식생 검색에 공간 격자를 사용하고, 시야 밖 먼 나무를 렌더 제출 목록에서 뺍니다. 변경된 맵의 정적 음영도 다시 생성했습니다.

[전후 화면·수치·주행 영상·검증 기록](docs/validation/v87-map-drive.md)

## 차량 바퀴·타이어 파손 개선 (버전 86)

- 포터·E2200·IZH와 기본 대체 차량의 바퀴를 각각의 이동 거리와 반지름으로 굴립니다. 앞바퀴 안쪽·바깥쪽 조향각을 구분하고, 핸드브레이크를 당기면 뒷바퀴를 잠급니다.
- 실사 모델에서 차체에 남아 있던 타이어 조각을 다시 분리하고 회전축을 보정했습니다. 타이어를 총으로 맞히면 고무가 손상되고 타이어가 작게 주저앉으며 파열음·공기 빠지는 소리·파편이 나옵니다.
- 타이어 파손 개수에 따라 가속·최고속도·접지력이 줄고 한쪽 파손 시 약하게 쏠립니다. 운전 중 파손 개수를 표시하고 차량 재생성 시 복구합니다.

[원인·전후 화면·주행 영상·검증 기록](docs/validation/v86-vehicle-wheels.md)

## 큰 수류탄 폭발·실사풍 화염병 (버전 85)

- 수류탄의 섬광 크기를 3배로 키우고 지속 시간을 늘렸습니다. 폭발 분출·연기·지면 먼지·파편도 함께 확장했습니다.
- 화염병은 새 실사풍 화염 원화 16장을 보간해 재생합니다. 연료면에 이어지는 불길, 갈라지는 끝부분, 검은 연기와 작은 불티를 사용합니다.
- 새 텍스처는 시작 화면을 기다리게 하지 않고 한 번만 불러옵니다. 누락 시 내장 불꽃을 사용하며, 품질별 고정 풀과 기존 피해·반경·지속 시간은 유지합니다.

[전후 화면·불길 영상·검증 기록](docs/validation/v85-throwable-vfx.md)

## 차량·총기 사운드·투척 효과 개선 (버전 84)

- 포터·E2200·IZH와 기본 대체 차량의 내구도를 320에서 1,600으로 5배 높였습니다. 피해에 따른 연기·출력 저하·화재와 재생성도 새 내구도 비율을 따릅니다.
- 총기 30종의 발사음 180개를 새 압력파·몸통·가스·약실 공명으로 다시 만들었습니다. 장전·조작음도 총별로 재가공한 독립 뱅크 30개로 교체했습니다. 연사·소음기·원거리·음소거와 파일 누락 시 새 총성을 생성하는 경로를 유지합니다.
- 수류탄은 짧은 섬광 뒤에 흙먼지·연기·고체 파편이 퍼집니다. 화염병은 병이 사라지면서 병 조각과 불꽃이 흩어지고, 바닥 불길·검은 연기·불티·그을음으로 이어집니다. 기존 투척 피해·범위·지속 시간은 유지합니다.
- 효과는 품질별 개수 제한과 고정 풀을 사용합니다. 연속 폭발·화염병 30쌍 검사에서 장면 객체·GPU 지오메트리·텍스처 수가 늘어나지 않았습니다.

[전후 화면·차량 실사격·검증 기록](docs/validation/v84-vehicle-audio-vfx.md) · [총성·조작음 듣기](docs/validation/v84-audio.html)

## 플레이 품질·훈련 기록 개선 (버전 83)

- 입자를 재사용하고, 늦게 도착한 총기의 텍스처·셰이더를 조준·사격·장전 중이 아닌 틈에 준비합니다. 설정에서 최대 60초의 실제 PC 성능을 기록하고 평균 FPS·1% 하위 FPS·긴 프레임과 당시 동작을 JSON으로 저장할 수 있습니다.
- 모든 총기의 달리기 자세가 조준으로 자연스럽게 복귀합니다. 무기 교체의 내려가기·올라오기와 장전 종료·취소 후 자세를 짧게 연결합니다.
- 적 봇은 가려졌던 같은 적을 다시 볼 때도 재조준하며, 거리·이동에 따른 조준 오차를 유지합니다. 장전 중 엄폐 목적지가 다른 물체 안에 있거나 실제 적의 높이에서 노출되는 경우를 제외합니다.
- 체력·탄약·미니맵을 분리하고 작은 화면에서도 배치합니다. 탄약 부족·장전·총구 막힘을 표시하며 같은 위치에서 연속으로 받는 피해 방향은 합칩니다.
- 메뉴·훈련장·일시정지의 **훈련 기록**에서 10 / 25 / 50 / 100m의 30초 측정을 시작합니다. 같은 총·거리의 최근·이전·최고 기록으로 명중률·헤드샷 비율·처치 수·첫 명중부터 처치 시간을 비교합니다. 이동·총기 변경·투척 시 중단하며 완료한 기록 60개를 브라우저에 보관합니다.

## 시작 로딩 개선 (버전 82)

- Three.js 부가 모듈과 게임 스크립트를 미리 내려받습니다. 게임 스크립트는 기존 순서로 실행하며, 필수 파일이 없으면 오류를 표시하고 멈춥니다.
- 독립적인 맵 에셋·총기·캐릭터·장전 데이터·차량 준비를 겹치고, M4·Glock 파일 해석도 맵 생성 중에 진행합니다. 메뉴가 열릴 때는 기존 모델이 모두 준비되어 있습니다.
- 맵·식생·텍스처 품질과 v81의 선명도 설정을 유지합니다. 모델 누락 시 기본 모델로 시작하는 복구 경로도 유지합니다.

## 화면 선명도·얇은 선 개선 (버전 81)

- 출력 캔버스를 모니터의 실제 픽셀 비율로 유지합니다. 자동 렌더 해상도는 중간·높음에서 85% 아래로 내려가지 않습니다.
- 화면·그래픽 설정의 렌더 해상도를 자동 / 67% / 75% / 85% / 100%로 선택합니다. 고정 해상도는 품질 자동 조절과 독립적으로 유지되며 FPS 표시줄에도 자동·고정을 표시합니다.
- 업스케일 뒤 대비 적응형 선명화를 적용합니다. 설정의 선명화를 0으로 내리면 끌 수 있습니다. 배경을 낮게 그려도 총·손·레티클은 네이티브 해상도로 합성합니다.
- 일반 이미지 텍스처에 최대 16x 비등방성 필터와 밉맵을 적용하고, 낮음부터 MSAA를 사용합니다. MSAA가 없는 기기는 FXAA로 보완합니다. 잎·알파 테스트 재질에는 MSAA 알파 커버리지를 적용하고, 가는 난간·울타리는 최소 화면 굵기를 유지합니다.

## 전투·환경 품질 개선 (버전 80)

- 실제 벽·창문·천장으로 소리의 차폐를 계산합니다. 방·복도·넓은 실내의 잔향을 구분하고, 열린 창문으로 들리는 소리와 벽·층 너머 소리를 다르게 처리합니다.
- 맞은 방향·부위에 따라 머리·어깨·몸통·다리가 반응합니다. 사망 자세는 주변 벽과 경사면을 고려하고, 가까운 시체의 실제 스킨 접촉점으로 바닥 침투를 보정합니다.
- 총기 30종의 실제 총구 위치를 이용해 벽 앞에서 총과 양손을 함께 접습니다. 막힌 동안에는 조준·발사를 제한하고 탄약을 소비하지 않습니다. 공간이 생기면 원래 자세로 복귀합니다.
- 콘크리트·나무·금속·지면의 탄흔을 구분하고 탄종·입사각을 반영합니다. 가까운 탄착에는 입체 파편을 사용하며, 탄흔·파편은 개수와 수명을 제한합니다.
- 실제 창문 개구부와 햇빛 방향으로 바닥의 광패치를 배치하고, 실내외 밝기를 완만하게 전환합니다.
- 건물 바닥 높이와 면의 모서리에 맞춰 때·마모·거칠기를 더합니다. 기존 정적 주변 음영과 원거리 모델을 유지합니다.

## 기존 요소 품질 개선 (버전 79)

- CC0 발소리·접촉음 25개를 연결하고, 실제 지형 재질에 따라 풀·흙·모래·자갈·포장면·나무·금속을 구분합니다. 발소리와 보행 주기는 실제 이동 거리를 따릅니다.
- 가까운 캐릭터의 발 접촉과 경사면 보정, 실제 군인 골격의 다리 길이·신발 높이 보정, 앉기·엎드리기 전환을 적용했습니다. 엎드린 총의 높이와 손 위치도 함께 맞췄습니다.
- 총기 30종의 금속·도장·플라스틱·목재·장갑 재질을 조정하고, 1인칭 조명을 보강했습니다.
- 화면 입자와 렌즈 색 번짐을 줄였습니다. 설정에서 입자·색 번짐·가장자리 어두움·어두운 부분 보정을 저장해 사용할 수 있습니다.
- 봇의 벽 앞 좌우 반복 반전, 장전 중 엄폐 지점 변경, 도착 경계에서 자세가 반복되는 동작을 다듬었습니다.
- 총기와 나무의 거리별 모델을 전환 구간에서 점진적으로 연결합니다. 나뭇잎은 MSAA를 쓰는 품질에서 알파 커버리지를 사용하며, 숲 밀도에 따른 표시 반경도 부드럽게 바뀝니다.

## 화질·메모리·로딩 최적화 (버전 78)

- 배경 해상도를 낮출 때 총·손은 화면 해상도로 따로 합성합니다. 배경 해상도가 충분하면 기존 렌더링 경로를 사용합니다.
- 총기 30종에 실제 경량 모델 두 단계를 추가했습니다. 12m·28m에서 전환하며 확대 조준에는 상세 모델을 더 오래 유지합니다.
- 시작할 때 모든 1인칭 모델을 만들지 않고 장비에 필요한 모델을 생성합니다. 실사 장전 팩도 해당 총을 장비할 때 요청하며, 조준·장전 중에 도착한 팩은 동작이 끝난 뒤 적용합니다.

- 지형·건물 텍스처에 밉맵이 포함된 KTX2 압축본을 추가했습니다. 지원하지 않는 GPU나 로딩 실패 시 기존 JPEG를 사용합니다.

## 총성·장전 사운드 (버전 74)

[게임 믹스 미리듣기](docs/validation/v74-weapon-audio.mp3) · [검증 기록](docs/validation/v74-audio-checks.md)

- 총기 15종의 기존 실총 녹음을 다시 편집했습니다. 콜옵 4처럼 발사 순간이 짧고 선명하게 들리도록 하고, 녹음에서 뽑은 저·중음으로 타격감을 더했습니다. 과도했던 음높이 변화와 긴 울림을 줄였습니다.
- 탄창 분리·삽입, 노리쇠·슬라이드, 탄 삽입 소리를 각각 또렷하게 다듬고 손동작 이벤트에 맞춰 재생합니다. 자동화기는 작은 후속 작동음을 더하며, 수동 볼트와 펌프는 기존 조작 타이밍을 따릅니다.
- 연사 때 앞 발의 잔향이 쌓이지 않게 하고, 소음기는 발사음을 줄이면서 가까운 기계음을 남깁니다. 다른 플레이어의 사격·장전음에는 거리·방향·음속 지연을 적용합니다.
- 스테레오 한쪽의 파열음이 먼저 나와도 잘리지 않게 하고, 오디오 뱅크의 다음 소리가 섞이지 않게 재생 범위를 제한했습니다. 녹음 파일이 없을 때 사용하는 대체 사운드도 총기 음량 0 설정을 따릅니다.
- `node tools/check-weapon-audio.cjs`는 실제 게임의 총기별 장전 이벤트와 최종 오디오 믹스를 검사합니다. 실총 녹음의 출처와 재현 방법은 [CREDITS](assets/audio/weapons/CREDITS.md)에 있습니다.

## 총을 쥐는 손·팔 자세 (버전 73)

[전후 비교](docs/validation/v73-hand-comparison.jpg) · [15종 전체 자세](docs/validation/v73-all-weapon-holds.jpg) · [검증 기록](docs/validation/v73-hand-checks.md)

- 총기 15종의 지향·조준·이동·질주·사격·장전 자세를 실제 게임 화면과 양쪽 측면에서 확인했습니다. 총마다 손 위치와 손가락 굽힘을 맞추고, 손목 이동에 팔꿈치와 소매도 함께 따라갑니다.
- SC-17·MK-14·M-1014·AA-12처럼 다른 총의 애니메이션을 공유하는 모델은 해당 총의 그립과 앞손잡이에 맞춥니다. AA-12는 큰 드럼 탄창의 표면에 맞춰 장전 중 손 위치도 보정합니다.
- 총을 쥐는 동안 장갑이 총에서 미끄러지지 않게 하고, 장전·펌프·볼트를 조작하는 손은 원본 동작을 따라갑니다. 비균일한 FBX 크기 변환을 보존하고, 다음 프레임을 계산하기 전에 보정을 복원해 손 변형과 누적 오차를 막습니다.
- `node tools/check-hand-poses.cjs`: 실제 스킨 메시로 손·총 표면 교차, 자세 전환 중 그립 유지, 장전 및 반복 적용을 검사합니다. 변형된 삼각형을 검사하므로 방아쇠울처럼 열린 메시도 측정할 수 있습니다. 장갑의 기존 접촉 두께를 허용하는 회귀 검사이며, 모든 접촉을 0으로 판정하는 검사는 아닙니다.

## 총기별 사격 움직임 (버전 72)

[사격 움직임 전후 비교](docs/validation/v72-recoil-comparison.jpg) — 카메라를 고정한 실제 게임 화면이며, 사격 전·50ms 후·복귀 모습을 비교합니다.

- 총기 15종에 각각 다른 후퇴 거리, 총구 들림, 좌우 비틀림, 복귀 속도를 적용했습니다. 소총·산탄총은 어깨, 권총은 손목을 중심으로 총과 손이 함께 움직입니다.
- 빠른 후퇴 뒤 총구가 들리고 감쇠하며 복귀합니다. 연사 시 기존 움직임에 다음 발의 충격을 더해 매번 처음 자세로 끊기지 않습니다. 자동 장전 총기는 작동부 복귀의 작은 후속 충격을 더하며, 펌프·볼트·중절식·리볼버는 기존 기계 동작을 유지합니다.
- 무작위 사격 화면 떨림과 중복 총몸 반동을 정리했습니다. 가져온 모델의 슬라이드·노리쇠·손가락 애니메이션은 유지하고, 조준·앉기·엎드리기·반동 감소 부착물이 보이는 반동에도 반영됩니다.
- `node tools/check-aim.cjs`에 단발 30조건, 연사·FPS 90조건, 실제 모델·대체 모델 표시 60조건, 자세·부착물 검사를 추가했습니다. 기존 조준 정렬·탄도·장전 검사도 함께 실행합니다.

## 실제 조준기 정렬 수정 (버전 71)

[조준 전후 비교](docs/validation/v71-aim-comparison.png) — 분홍색 십자가는 화면 중앙입니다.

- 총몸의 가장 높은 정점 대신 실제 가늠쇠 끝과 가늠자 홈·구멍 중심을 사용합니다. M4의 가늠자 높이, 권총의 좌우 치우침, SC-17·AA-12의 조준기가 시야를 가리는 문제를 바로잡았습니다.
- 정조준 중 대기 애니메이션·호흡·마우스 스웨이 때문에 총만 화면 중앙에서 벗어나지 않도록 합니다. 사격 반동과 장전 동작은 계속 재생합니다.
- **FPS에 따른 낙차 차이 수정**: 탄을 프레임 끝 속도로 한 프레임 내내 이동시키던 계산을 평균 속도로 바꿨습니다. 산포·탄속 무작위를 제외한 기준 탄도 검사에서 10·50·100m, 30/60/144 FPS의 최대 탄착 오차가 약 6.07cm에서 0.14cm로 줄었습니다.
- 모델 변환 검사는 게임과 같은 부착물 경로·조준경 높이 정보를 사용합니다. Node 검사는 메시·모션을 검증하고, 브라우저 검사는 실제 텍스처 로딩도 확인합니다.
- `node tools/check-aim.cjs`: 실제 우클릭 조준·좌클릭으로 10·50·100m 표적 명중, 총기 15종의 가늠쇠·레드닷·홀로 39조합을 30/60/144 FPS와 16:9·4:3 화면에서 확인합니다. 조준선 메시 간섭, 기준 탄도 135조건, 반동 복귀 15조건, 빈 탄창·잔탄 재장전 후 조준 30조건도 검사합니다.

## 영점 맞추기 (버전 70)

- **가늠쇠를 탄착점에**: 총알은 화면 정가운데로 나가는데, 조준할 때 총을 '총 윗면 + 4 mm + 총별 들어올림(최대 3 cm)'만큼 내려 놓고 있어서 보이는 가늠쇠가 탄착점보다 0.5~4° 아래에 있었다(50 m에서 수십 cm~3 m 위로 맞음). 이제 가늠쇠 끝을 화면 정가운데에 정확히 둔다.
  - 가늠쇠가 낮게 잡히고 뒤쪽이 시선을 가리는 총(KA-47, SA-12, AA-12, R-45)은 가늠자 윗면을 조준선으로.
  - MK-14: 앞·뒤 고리 조준기의 가운데를 조준선으로 직접 지정(총이 위로 들려 보이던 것도 바로잡힘). 조준경을 달면 고리 조준기를 접는다.
  - G-18: 1 mm 내려 있던 것을 0으로.
- **낙차 보정(영점)**: 총알은 중력으로 떨어지므로, 조준 중에는 화면 가운데에 걸린 것(지형·건물·사람·과녁)까지의 거리에서 정확히 맞도록 그만큼 살짝 위로 쏜다. 지향 사격은 50 m 영점. 측정상 11~70 m 에서 조준점과 탄착점 차이 1 cm 이하(0.2 mrad 이하).
- 레드닷·홀로·배율 조준경은 원래 맞아 있었다(조준점이 정가운데).

## 첫 화면(메뉴) 정리 (버전 69)

- 왼쪽 칸을 로고 · 모드/설정 · 버튼 줄로 나눴다. **게임 시작 · 훈련장 · 전적 · 설정** 버튼이 늘 화면 안에 보인다(720p 노트북에서 스크롤해야 보이던 문제).
- 설정을 **매치 설정**(닉네임 · 인원 · 난이도 · 시작 무기 · 시간대)과 **화면 · 조작**(그래픽 · 목표 FPS · FPS 표시 · 감도) 탭으로 나눴다. 마지막에 본 탭을 기억한다.
- 1인칭 총 모델 바꾸기(FBX/ZIP)는 '고급'으로 접어 두었다.
- 오른쪽에 늘 떠 있던 조작법을 없애고, 버튼 줄의 **조작법** 버튼으로 여는 창으로 옮겼다(✕ · 바깥 클릭 · Esc 로 닫기). 휴대폰에서는 버튼을 숨긴다.
- 좁은 창·휴대폰: 조작법은 숨기고, 설정 줄은 이름 아래에 버튼을 꽉 차게 놓는다.

## 프레임·해상도 최적화 (버전 68)

측정부터 하고 고쳤다. 같은 판에서 바뀐 부분을 끄고/켜고 비교한 결과는 PR 설명에 표로 있다.

- **성능 오버레이**: 게임 중 `F3`, 또는 주소 뒤에 `?perf=1`. FPS·프레임 시간·1% low, 패스별 GPU 시간(그림자·장면·1인칭 총·블룸·색보정·FXAA·업스케일, GPU 타이머를 지원하는 브라우저), draw call·삼각형·텍스처/셰이더 수, 장면/화면 해상도, DRS 배율. 타이머가 없는 기기는 `?perf=sync`(느려짐).
- **벤치마크**: `node tools/bench-perf.cjs [출력폴더]` — 숲 한가운데 · 마을 위 고지대 · 교전 중 × 품질 4단계, 패스별 시간과 스크린샷. `MODES=off,on` 으로 같은 판에서 v68 최적화를 끄고/켜고 비교, `BREAKDOWN=1` 로 삼각형을 쓰는 물체 순위.
- **나무 재질**: 최저·낮음·중간에서 나무(가까운 줄기·잎, 먼 임포스터)를 램버트 재질로. 표준 재질 밝기의 대부분인 환경맵 간접광은 시간대가 바뀔 때 한 번 재서 더해 주므로 겉보기는 거의 같다. 나무가 많은 화면에서 장면 시간 약 40% 감소. 높음은 그대로.
- **시야 밖 자르기**: 가까운 나무·덤불은 카메라 둘레 전부가 아니라 앞쪽 부채꼴(+발밑 14 m, +해 반대쪽으로 드리우는 그림자)만 그린다. 풀은 풀이 없는 곳·시야 뒤의 묶음을 정점 셰이더 앞에서 버린다. 바위는 구역마다 전부 그리던 것을 한 덩어리로 묶고 품질별 거리(최저 170 m ~ 높음 460 m, 작은 바위는 더 가까이) + 시야 안의 것만. 숲에서 삼각형 약 45% 감소, 그림자 패스도 약 45% 감소.
- **후처리**: 톤매핑·sRGB(OutputPass)를 색보정 패스에 합쳐 전체 화면 패스 하나를 줄였다. 색수차·선명화·그레인은 0 이면 아예 계산하지 않는다.
- **업스케일**: 낮음·중간·높음에서 내부 해상도가 낮아지면 AMD FSR 1.0 EASU 방식으로 늘린다(선형보다 또렷). 최저는 가장 싼 선형+선명화.
- **동적 해상도(DRS)**: 내릴 때는 걸린 시간에 맞는 배율로 한 번에, 올릴 때는 올린 뒤 예상 시간이 목표 안일 때만. 올렸다가 곧 다시 내려가면 그 배율은 한동안(기다림 두 배씩, 최대 32초) 시도하지 않아 해상도가 오르락내리락 깜빡이지 않는다.
- **'자동' 품질 첫 실행 측정**: 저장된 단계가 없으면 메뉴 화면에서 단계별로 1~2초씩 재서 시작 단계를 정한다(GPU 타이머가 있으면 GPU 시간 기준).
- **비등방 필터**: 단계별 상한(최저 2 · 낮음 4 · 중간 8 · 높음 16).

## 저사양 계단 현상 · 전체 최적화 (버전 67)

- 저사양(최저/낮음)에서도 안티에일리어싱: 내부 해상도에서 FXAA 를 먼저 걸고, 화면 해상도로 따로 올려 그린다(업스케일 + 약한 선명화). 저해상도로 그린 화면을 그대로 늘려 생기던 계단·자글자글함이 줄어든다.
- 화면 해상도는 MSAA 가 없는 단계에서 기기 배율 1 로 묶고, 동적 해상도(DRS)는 내부 해상도만 내린다 → 글자·HUD 는 덜 뭉개진다.
- 나뭇잎·풀이 멀리서 점점이 흩어져 보이던 것: 밉맵 단계에 맞춰 알파를 보정해 멀리서도 잎이 꽉 차 보인다.
- 내부 해상도가 낮을 때 필름 그레인·색수차·선명화를 줄여 노이즈가 덜 보인다.
- 처음 보는 텍스처를 판 시작 후 프레임당 3 ms 안에서 미리 올려, 숲에 처음 들어갈 때 등 멈칫하던 것을 없앴다.
- 탄피·예광탄: 보이는 것이 없으면 반복을 건너뛰고, 땅에 멈춘 탄피는 다시 계산하지 않는다.

- **사격장** (사격대·총 테이블·7~100 m 표적·움직이는 표적·강철판)과 **운전 코스**는 그대로 옮겼습니다.

## 1인칭 파지·자세 점검 수정 (버전 57)

- **전력질주 자세**: 카메라를 축으로 총을 30° 가까이 돌려 총이 화면 옆으로 날아가거나 개머리판이 화면을 덮던 것을, 총몸 뒤쪽을 축으로 살짝 내리고 기울이는 자세로 바꿨습니다.
- **지향 자세 기울기(캔트) 제거**: v56 에서 넣은 3~4° 기울기를 없앴습니다.
- **바꿔 낀 총의 손잡이 위치**: SC-17 · MK-14 · AA-12 · M-1014 는 오른손이 권총 손잡이보다 앞(탄창 쪽)을 쥐고 손잡이가 비어 있었습니다 → 총을 앞뒤로 옮겨 손잡이가 손 안에 오게 했습니다 (M-1014 는 조금 올림).
- **R-45 리볼버 팔**: 오른팔을 옆으로 뻗던 원본 자세를 팔 IK(손은 그대로, 어깨를 내리고 팔꿈치를 아래로)로 고쳐, 조준 때 화면 오른쪽을 덮던 팔뚝이 아래로 내려갑니다.
- **권총(M-1911 · DE-7 · P-92) 지향 자세**: 주먹 뒤만 보이던 각도를 바꿔 총 옆면과 쥔 손이 보이게 했습니다.
- **S-12 · M-1014 조준**: 오른손이 화면 오른쪽을 크게 덮던 것을 총을 더 앞으로 빼서 줄였고, 장전 동작 때 총이 카메라 앞으로 다가오던 것도 뒤로 물렸습니다.
- **장전·전력질주 중 소매 끝**: 위팔(어깨) 정점을 숨기고(ACR·Remington 팩은 장전 중에만), 팔 재질을 양면으로 그려 잘린 소매 끝이 빈 구멍 대신 소매 안쪽으로 보입니다.
- **권총 손 크기**: XD 권총 팩은 팔이 총에 비해 2배 가까이 커서, 실제 크기 M-1911·DE-7 이 거대한 주먹 위에 얹혀 보였습니다 → 손을 주먹 가운데 기준으로 줄이고(아래팔도 굵기만 같이) 권총을 2 cm 내려 손잡이가 손 안에 들어가게 했습니다.
- **팔로 잘못 분류된 총 부품**: ACR 팩의 탄창, XD 팩의 탄창, Remington 팩의 낱개 탄이 '팔'로 분류돼 소매 색으로 칠해지고 잘려 나갔습니다. 특히 SC-17 · MK-14 에는 팩의 ACR 탄창이 바꿔 낀 총 탄창 옆에 하나 더 보였습니다 → 뼈 하나에만 묶인 메시는 팔에서 빼고, 탄창은 바꿔 낀 총에서 숨깁니다.
- **M-1014 오른손**: 손이 권총 손잡이 위(총몸 위)에 떠 있던 것을 앞손을 축으로 총을 7° 숙여 손잡이에 닿게 했습니다.
- 바꿔 낀 총도 지향 자세는 팩 총 기준으로 잡아, AA-12 지향 화면 왼쪽에 떠 있던 팔 조각이 사라졌습니다. AA-12 조준 때 가늠자 블록이 덜 가리게 조금 앞으로 뺐습니다.

## 1인칭 화면 정리 · 팔 통일 · 저격소총/리볼버 장전 동작 (버전 56)

- **총이 화면을 덜 가리게**: 팩마다 제각각이던 지향 자세를 모든 총에 같은 규칙으로 잡습니다. 가늠자가 화면 오른쪽 아래 정해진 자리에 오고, 총구는 살짝 가운데를 향합니다. 화면 밖 어깨·위팔 쪽 팔은 늘 그리지 않아 잘린 소매 끝이 보이지 않습니다.
- **장전할 때 총을 들어 올려** 손동작이 화면 안에서 보입니다.
- **권총 반동 새로 만들기**: 팩의 과장된 사격 동작(총이 크게 뒤집힘) 대신, 손목을 축으로 짧게 튀었다가 스프링처럼 돌아오고 슬라이드가 순간 후퇴합니다. 조준 중에는 덜 튑니다.
- **손 통일**: 모든 1인칭 팩의 팔을 같은 검은 전술 장갑 + 레인저 그린 소매로 칠합니다 (원본 텍스처의 주름·명암은 그대로).
- **KR-98 저격소총**: 볼트액션 1인칭 팩(사격 뒤 볼트 당기기, 탄창 빼고 끼우기). 탄창식 장전(2.4초)으로 바뀌었습니다.
- **R-45 리볼버**: 실린더를 열어 탄피를 털고 한 발씩 넣고 닫는 1인칭 팩. 장전 3.0초.

## 레이트레이싱 로딩 중 준비 · 1인칭 총 자세 (버전 54)

- 레이트레이싱을 켜 두면 장면 준비(광선 추적용 BVH 만들기, 몇 초)를 **로딩 화면에서** 미리 합니다. 게임을 처음 불러올 때, 판을 시작할 때, 메뉴로 돌아갈 때, 설정에서 켤 때 "레이트레이싱 장면 준비 중..." 화면이 잠깐 뜨고, 게임 중에는 다시 준비하지 않아 멈추지 않습니다.
- 그래픽 단계가 자동으로 바뀔 때마다 장면을 다시 준비하던 것도 없앴습니다.
- **1인칭 총 자세 다듬기**: 실사 팩 총(KA-47 · SC-17 · MK-14 · SA-12 · AA-12 · S-12 · M-1014 · P-92 · M-1911 · DE-7)이 옆으로 기울어(캔트) 보이던 것을 바로 세웠습니다. 총 몸의 위·아래 방향을 정점 분포로 찾아, 지향 자세에서는 기울기를 없애고 총구 방향을 조금 앞으로 돌리고, 조준하면 가늠자·가늠쇠(또는 조준경)를 시선과 정확히 나란히 맞춥니다.
- 조준할 때 팔·총을 앞으로 크게 밀던 것을 최대 7 cm 로 줄이고, 원래 화면 밖이던 어깨 쪽 소매 끝은 조준 중에 그리지 않아 잘린 팔 끝이 보이지 않습니다 (장전 동작 중에는 팔 전체가 그대로 보입니다).

## 현대 군사 FPS 톤 · 군용 HUD · 한글 간판 · 실사 차량 재질 (버전 52)

모던 워페어 4 같은 사실적인 현대 군사 FPS 분위기를 목표로 화면 전체를 다듬었습니다. 다른 게임의 에셋 · UI · 로고는 쓰지 않았고, 셰이더와 CSS 를 새로 짜서 비슷한 느낌을 냈습니다.

- **색감 · 조명**: 새 색보정 단계가 들어갑니다. 쨍한 풀색은 올리브 · 흙빛으로 누르고, 그림자는 청록 · 밝은 곳은 주황으로 나눠 물들입니다. 대비를 올리고 채도는 낮췄으며, 가벼운 선명화 · 가장자리 색수차 · 비네트 · 움직이는 필름 그레인이 더해집니다. 낮 햇빛은 더 강하고 그늘은 더 짙어졌고, 먼 곳 안개도 조금 짙어졌습니다.
- 그래픽 **낮음** 단계도 이제 후처리(색보정)를 씁니다 (블룸은 끈 채). 최저 단계만 예전처럼 바로 그립니다.
- **HUD**: 상자 대신 흰 글자 · 얇은 선 · 각진 모서리. PC 화면에서는 미니맵이 왼쪽 위, 체력이 왼쪽 아래, 탄약 · 무기 칸이 오른쪽 아래로 옮겨졌습니다 (휴대폰 배치는 그대로). 숫자는 좁은 군용 글꼴(Barlow Condensed, Google Fonts · OFL)입니다.
- **메뉴**: 검은 배경 · 흰 선택 칸 · 금색 시작 버튼의 각진 디자인.
- **맵**: 상점 건물에 한글 간판(편의점 · 약국 · 치킨 · 부동산 · 분식 · PC방 · 노래연습장 · 세탁소 · 정육점 · 휴대폰 · 마트 · 미용실)이 붙습니다. 밤에는 은은하게 빛납니다.
- **차량**: 하얗던 창문을 짙은 반사 유리로, 차체는 클리어코트 도장(조금 바랜 색), 범퍼 · 플라스틱은 무광, 바퀴 쪽 아래일수록 흙먼지가 묻습니다.
- 총기는 버전 51 의 실사 팩, 투척무기는 버전 46 의 실사 모델을 그대로 씁니다.

## 총기별 실사 장전 동작 · 차량 재생성 (버전 51)

- **장전 동작 교체**: 총마다 그 총에 맞는 1인칭 애니메이션 팩(Sketchfab CC-BY-4.0, GitHub 에 올라온 사본에서 받음)의 팔·총·사격·장전 동작을 씁니다. KA-47 은 AK-74 팩(새 탄창으로 헌 탄창 쳐내기 → 끼우기 → 빈 총이면 장전손잡이), SA-12 · AA-12 는 Saiga 팩, SC-17 · MK-14 는 ACR 소총 팩(+꺼내기 동작), S-12 · M-1014 는 Remington 펌프 산탄총 팩(한 발씩 밀어 넣고 마지막에 펌프), P-92 는 9mm 권총 팩(+꺼내기, 빈 총 장전 따로), M-1911 · DE-7 은 XD 권총 팩입니다. 탄창식 총은 일반 장전과 빈 총 장전이 다른 동작이고, 소리(탄창 빼기·끼우기·노리쇠)는 동작에 맞춰 납니다.
- 장전 시간은 원래 게임 값을 기준으로 하되 동작이 너무 빨리 감기지 않도록 최대 1.3 배까지 늘어납니다 (예: KA-47 2.0 → 2.6 초, P-92 1.16 → 1.5 초). 산탄총은 한 발 0.68 초입니다.
- 조준(우클릭)하면 총의 가늠선을 시선과 나란히 돌려 가늠쇠(또는 조준경 중심)를 화면 가운데에 둡니다. 조준경 · 소음기 · 손잡이 · 레이저도 새 총에 붙습니다.
- 팩은 게임 시작을 막지 않고 뒤에서 하나씩 받습니다 (들고 있는 총부터, 합쳐 약 11 MB). 받기 전이나 받지 못하면 그 총은 예전 1인칭 모델과 장전 동작을 그대로 씁니다.
- **맞는 무료 팩을 찾지 못한 총**: KR-98(볼트액션 한 발씩), DB-2(꺾어 여는 더블배럴), R-45(리볼버)는 기존 장전 동작을 유지합니다. AR-7(M4) · G-18(Glock)은 원래부터 실사 팩을 씁니다.
- **차량 재생성**: 터진 차는 잔해로 25초 남았다가 처음 세워져 있던 자리에 새 차(같은 차종, 내구도 가득)로 다시 나옵니다. 그 자리 5 m 안에 사람이나 다른 차가 있으면 비킬 때까지 기다립니다.

## 레이트레이싱 (실험, 버전 50)

- **설정 → 레이트레이싱**을 켜면 훈련장과 필드맵을 [three-realtime-rt](https://github.com/GoldwinXS/three-realtime-rt)(ThreeRT, MIT)로 그립니다. three.js 가 G-버퍼를 그리고, 장면 BVH(three-mesh-bvh)로 해·조명의 부드러운 그림자, 금속 반사, 고사양 기기면 1회 반사광까지 광선 추적합니다. 설정은 이 브라우저에 저장되고, 기본값은 꺼짐입니다.
- **필요한 것**: WebGL2 와 부동소수점 렌더 타깃을 지원하는 그래픽카드 (외장 그래픽 권장). 지원하지 않으면 "지원 안 됨"으로 표시되고 꺼진 채로 둡니다. 그래픽 장치가 감당하지 못해 화면이 끊기면 자동으로 꺼지고 저장됩니다.
- **ThreeRT 가 그리지 못하는 것은 기존 방식으로 덧그립니다**: 나무 · 풀 · 바위 · 모래주머니(인스턴스 모델), 하늘 · 구름 · 물 · 파티클 · 투명 효과. 이것들은 레이트레이싱 그림자를 드리우지 않습니다. 사람과 전리품도 성능 때문에 그림자 계산에서 뺍니다 (화면에는 레이트레이싱 조명으로 그려짐). 차량과 훈련장 표적은 움직이는 그림자를 가집니다.
- 판을 시작할 때 장면을 한 번 컴파일하느라 잠깐(1~3초) 멈출 수 있습니다. 켜져 있는 동안은 ThreeRT 가 목표 FPS(55)에 맞춰 스스로 품질을 조절하고, 게임의 동적 해상도 · 블룸 · 색 보정은 쉽니다.

## 봇 전술 · 설정 화면 (버전 36)

- **봇이 새 동작을 씁니다.** 엄폐물 모서리에서는 가운데서는 안 보이지만 옆으로 내밀면 보이는 쪽으로 기울여 쏩니다(어려움일수록 자주). 멀리 있는 적에게는 소총을 들고 엎드려 쏘고, 가까워지면 일어납니다. 플레이어 팀이 아닌 봇은 150m 넘게 가야 할 때 근처 지프를 타고 자기장 안으로 이동합니다. 가까이 적이 보이거나 맞으면 차를 세우고 내려서 싸웁니다. 운전하는 봇은 사람을 들이받을 수 있고, 다가오는 차의 엔진 소리가 방향대로 들립니다.
- **기울이면 히트박스도 따라갑니다.** 플레이어와 봇 모두 기울인 만큼 머리·상체가 옆으로 나오고, 3인칭 모델도 기울어진 자세로 보입니다. 엎드린 캐릭터는 기절 자세 대신 총을 앞으로 든 엎드려 쏴 자세를 씁니다.
- **설정 창**(메뉴의 "설정", 일시정지 화면의 "설정"): 정조준 감도, 배율 조준경 감도, 시야각(70~100°), 마우스 상하 반전, 전체·총소리·환경음 음량, 키 바꾸기. 이미 쓰는 키를 고르면 두 동작의 키가 서로 바뀌고, 메뉴의 조작법 표시도 바뀐 키로 나옵니다. 설정은 이 브라우저에만 저장됩니다(`js/settings.js`).
- **훈련장 운전 코스**: 사격장 동쪽에 사격장과 같은 높이로 고른 평지를 만들고, 폭 8m 아스팔트 순환 코스(약 100×84m, 모서리를 깎은 사각형)와 사격대 뒤에서 이어지는 진입로를 깔았습니다. 훈련장을 시작하면 진입로에 지프 두 대가 서 있고, 출발선과 모서리 고깔이 놓입니다. 코스 도로는 배틀로얄 지도에도 남아 있어 차량이 놓일 수 있습니다.
- **에셋 출처 정리**: 번들된 M4·Glock 1인칭 모델의 출처를 [`assets/models/viewmodels/CREDITS.md`](assets/models/viewmodels/CREDITS.md)와 메뉴의 "에셋 출처"에 적었습니다. Glock 모델은 받은 곳이 기록되어 있지 않아 "확인 필요"로 두었습니다.

## 성능 (목표 FPS)

- 메뉴의 **목표 FPS**(60/120/144)를 고르면 그 FPS를 유지하도록 **렌더 해상도를 자동으로 조절**합니다 (최저 55%까지). 좌상단에 `FPS · 해상도 %`가 표시됩니다.
- 브라우저는 모니터 주사율보다 빠르게 그릴 수 없습니다. 60Hz 모니터에서는 최대 60FPS이며, 이 경우 표시줄에 `모니터 60Hz`가 함께 나옵니다.
- 그래픽 프리셋: **자동(기본)** · 최저(해상도 60%, 그림자·풀·후처리 없음, 시야 750m) · 낮음(75%, 그림자 1024·나무 그림자 없음, 풀·후처리 없음) · 중간(100%, MSAA 2x) · 높음(최대 125%, MSAA 4x, 풀 밀도 최대).
- **자동 품질:** 그래픽 카드 이름으로 시작 단계를 고르고(내장 그래픽·휴대폰은 낮음), 게임 중 60fps 아래로 떨어지면 먼저 해상도를 낮추고 그래도 안 되면 한 단계씩 내립니다. 해상도 100%로 화면 주사율을 25초 넘게 유지하면 한 단계 위를 시험하고, 버티지 못한 단계는 다시 올리지 않습니다. 고른 단계는 다음 실행 때 그대로 시작합니다.
- **지형 LOD:** 섬을 200m 청크 64개로 나누고 카메라에서 먼 청크일수록 성긴 격자(최대 16칸 간격)로 그립니다 (예전 52만 → 약 4~5만 삼각형). 단계 사이 틈은 아래로 내린 '치마'로 가립니다.

## 훈련장

### 군사 사격장 시설 (버전 33)

Patch에서 가져온 Polyfork 모래주머니 벽, Poly Haven의 낡은 콘크리트 바닥과 보급 상자를 게임에 포함했습니다. 양옆 엄폐 구역, 4개 사격 부스의 번호판·낮은 칸막이, 탄약 상자·팔레트, 부착물 안내판과 안전 통로 표시가 추가됐습니다. 중앙 표적·이동 레일 구역은 비워 두었고, 새 엄폐물과 상자에는 이동·총알 충돌을 적용했습니다. 기존 총·부착물 테이블과 거리별 표적은 그대로 이용할 수 있습니다. 추가 파일을 직접 선택할 필요가 없습니다.

에셋 출처는 게임 메뉴의 **훈련장 에셋 출처**와 `assets/patch/range/CREDITS.md`에 있습니다.

메인 메뉴의 **훈련장** 버튼으로 혼자 사격 연습을 할 수 있습니다. 섬 남쪽의 평평한 사격장(지도에 '사격장')에서 시작하며, 봇·수송기·자기장은 없고 플레이어는 다치지 않습니다.

- 사격대 앞 테이블 4개에 **모든 총(소총 5 · 산탄총 5 · 권총 5)**, 조준경 5종, 투척무기 4종이 놓여 있습니다. **F**로 바꿔 들면 그 자리에 다시 놓입니다. 탄약은 무한입니다.
- **고정 표적**: 7m(2개) · 10 · 25 · 50 · 75 · 100m 사람 모양 표적. 체력 100을 모두 깎으면 뒤로 쓰러졌다가 2초 뒤 일어섭니다.
- **움직이는 표적**: 20m(걷기) · 40m(뛰기) · 60m(멈췄다 가기) 레일 위 표적.
- **강철판**: 110~118m, 맞으면 '땡' 소리와 함께 흔들립니다.
- 맞히면 명중 표시와 **피해 숫자**(머리는 노란색, 쓰러뜨리면 빨간색)가 뜨고, 화면 위에 명중률·헤드샷·최근 피해·쓰러뜨린 수가 표시됩니다. 거리별 피해 감소·헤드샷 배율은 실제 경기와 같습니다.

  | DE-7 | 총을 옆으로 눕혀 큰 탄창 교체, 무거운 슬라이드를 위에서 당김 |
  | R-45 | 실린더를 열고 총구를 들어 탄피를 털고, 총구를 숙여 스피드로더로 넣은 뒤 손목을 튕겨 닫음 |

  저격소총은 쏠 때마다 볼트를 당깁니다.

## 새 기능 (버전 31)

- **자세·이동**: `Q`/`E` 좌우 기울이기, `Z` 엎드리기(반동·탄퍼짐 감소, 느린 이동), 0.5~1.6m 높이의 벽·창틀·상자 앞에서 `Space`로 넘기.
- **장비 등급**: 방탄조끼·헬멧·가방이 Lv.1~3으로 나뉩니다. 높은 등급만 줍고 입던 것은 내려놓습니다. 가방 등급이 높을수록 탄약·투척무기·치료 아이템을 더 많이 들 수 있습니다.
- **전투 피드백**: 맞힌 곳에 피해 숫자가 뜨고(방탄 장비에 막히면 파란색), 방탄 장비 피격음이 다릅니다. 가까운 적의 재장전 소리가 방향과 거리에 맞게 들립니다.
- **보급 상자**: 2분 30초부터 수송기가 안전 구역에 낙하산 상자를 떨어뜨립니다(최대 4번). 빨간 연막과 지도 표시로 찾을 수 있고, 상위 총기와 Lv.3 장비가 들어 있습니다.
- **차량**: 도로 옆에 세워진 지프를 `F`로 타고 내립니다. `W A S D` 운전, `Space` 브레이크. 적을 들이받을 수 있고, 세게 부딪히면 다칩니다. 엔진 소리는 주변 적이 듣습니다.
- **킬캠·관전**: 죽으면 5초 동안 나를 처치한 적을 따라가며 무기·거리·남은 체력을 보여 줍니다. 결과 화면의 **관전하기**로 남은 경기를 볼 수 있습니다(좌클릭 대상 전환, Esc 복귀).
- **전적·업적**: 메뉴의 **전적 · 업적**에서 승률·처치·명중률·최장 처치 거리와 업적 10종을 봅니다. 이 브라우저에만 저장됩니다.
- **시간대·날씨**: 낮·노을에 밤·안개·비·무작위를 더했습니다. 밤·안개·비에는 적도 멀리 보지 못합니다. `L`로 손전등을 켭니다.

코드: `js/extras.js`(피해 숫자·전적·보급·날씨), `js/vehicles.js`(차량). 휴대폰 터치 조작에도 새 동작 버튼(기울이기·엎드려·손전등)이 있습니다.

### 휴대폰 버튼 추가 (버전 32)
기울이기(◀/▶), 엎드려, 손전등 버튼을 터치 화면에 추가했습니다. 위치·크기는 "휴대폰 버튼 위치 바꾸기"에서 바꿀 수 있습니다. 차량은 줍기 버튼으로 타고 내리고, 이동 조이스틱과 점프 버튼(브레이크)으로 운전합니다.

## 실총 사운드 · 장전 리듬 (버전 28)

- 총소리와 장전음은 모두 실제 총기 녹음(The Free Firearm Sound Library, CC0)에서 잘라 냈습니다. 내 총은 사수 뒤에서 녹음한 스테레오 2테이크를 번갈아 쓰고, 다른 사람의 총은 거리에 따라 근거리 녹음에서 원거리 녹음으로 넘어가며 음속만큼 늦게 들립니다.
- 탄창 분리·삽입, 장전 손잡이·슬라이드·볼트·펌프, 산탄 삽입, 리볼버 실린더, 공격발 소리를 총마다 실물 녹음으로 냅니다. 출처: [오디오 출처](assets/audio/weapons/CREDITS.md), 설명: [사운드 노트](tools/WEAPON_AUDIO.md).
- 빈 총 장전은 잔탄 장전의 1.1배입니다(이전 1.35배). 장전 손잡이를 당길 때 총이 반대로 홱 뒤집히던 기울기와 머리 위로 크게 돌던 팔 동작을 줄였습니다.

## 장전 모션·손·팔 모델 확인 (버전 18)

`start.bat` 실행 후 **http://localhost:8080/tools/reloads.html**에서 총기 30종의 빈 탄창/잔탄 장전을 비교할 수 있습니다. 0.25×·0.5× 슬로모션, 타임라인 이동, 1인칭·측면·사선 카메라를 지원합니다. 게임과 같은 모델·팔 IK·재장전 로직을 사용합니다.

- 권총 4종은 탄입대 위치·삽입 리듬·슬라이드 조작이 각각 다르고, 잔탄 장전에서는 헌 탄창을 손에 쥐어 보관합니다.
- 총마다 어깨의 선행 동작·탄창을 찾는 자세·손목 방향·복귀의 무게감이 다릅니다. 드럼 탄창은 무겁게, 소형 권총은 짧고 빠르게 반응합니다.
- 탄창 삽입·드럼 두드리기·노리쇠 열기/닫기·리볼버·산탄총 소리는 실제 동작 시각에 맞춥니다.
- 손 모델은 길이가 다른 손가락과 연속 관절 표면, 엄지 대립, 손목 테이퍼를 반영했습니다. 물체를 잡는 동안 접촉점을 고정하고, 산탄은 엄지·검지 사이에 붙입니다. **왼손 확대 / 오른손 확대** 카메라로 확인할 수 있습니다.
- 팔꿈치 방향과 어깨 이동을 연속적으로 처리하고, 손목의 비틀림을 아래팔 중간·끝으로 나눠 소매가 한꺼번에 뒤집히지 않게 했습니다. **팔 전체** 카메라에서 연결을 확인할 수 있습니다.
- S-12의 빈 총 시작 동작만 약 0.32초 늘려 펌프를 다시 잡는 동작을 분리했습니다. 다른 무기 장전 시간과 탄약 규칙은 유지합니다.
- 참고 자료와 총기별 연출 방향: [장전 모션 노트](tools/RELOADS.md). 손 모델: [손 리그 노트](tools/HANDS.md). 팔 연결 수정: [팔 모션 노트](tools/ARMS.md).

## 조준경

- **레드닷 · 홀로그램 · 2배율 · 4배율 · 8배율** 조준경이 전리품으로 나옵니다 (저격소총·지정사수소총은 조준경이 달린 채로 자주 나옴).
- 주우면 조준경이 없는 호환 총에 바로 장착되고, 남는 것은 가방에 들어갑니다. **V** 키로 들고 있는 총의 조준경을 바꿔 끼웁니다.
- 소총은 모든 조준경, 산탄총은 레드닷·홀로그램(·2배율), 권총은 레드닷만 달 수 있습니다 (리볼버 불가).
- 2배율 이상은 정조준하면 원형 조준경 화면으로 바뀌고, 4·8배율은 흔들림이 있어 **Shift**로 숨을 참아 잠시 안정시킬 수 있습니다.

시작 무기를 하나만 고르거나 **전부** 들고 시작할 수 있고(기본 총: AR-7 · S-12 · P-92), 맵 곳곳의 건물 안 전리품으로 다른 총도 주울 수 있습니다 (1·2·3번 슬롯에 동시에 보유).
