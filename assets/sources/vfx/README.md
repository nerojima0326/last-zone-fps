# v85 화염 원화

`pool-fire-v85.png`는 2026년 11월 23일 OpenAI ImageGen으로 이 게임을 위해 새로 제작한 실사풍 연료 화염 원화다. 실사 촬영 영상이나 외부 게임에서 추출한 이미지가 아니다. 생성 결과 원본을 보관하며, 실행 중에는 이 PNG를 내려받지 않는다.

- 정사각형 원화의 4×4 배치, 왼쪽부터 오른쪽·위에서 아래 순서로 16장이다.
- 요청한 표현은 얇게 갈라지고 말려 올라가는 휘발유 화염, 밝은 노란 중심·주황색 몸통·어두운 틈, 일정한 카메라와 바닥 기준선이다. 물체·장작·글자·그리드 선은 제외하고 배경은 방출광이 없는 검정으로 지정했다.
- 런타임 셰이더는 검은 배경을 광량으로 분리한다. 광량에서 알파를 구해 투명하게 만들고 알파를 곱한 상태로 두 프레임을 보간하므로 흰 여백이나 사각 배경을 표시하지 않는다.
- `node tools/prepare-fire-flipbook.cjs`는 ffmpeg로 1024×1024 WebP를 만들고 원본·배포 파일의 SHA-256을 매니페스트에 남긴다. 각 프레임은 256×256이며 기본 재생 속도는 초당 12장이다. 개별 불길의 위상과 속도를 조금씩 다르게 한다.
- 원화 재생성은 같은 이미지를 보장하지 않는다. 보관된 PNG에서 배포 파일을 만드는 변환 과정은 같은 ffmpeg 버전에서 재현할 수 있다.
