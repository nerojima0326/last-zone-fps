All models are converted to metres with the trigger as origin and muzzle toward −Z. Textures are resized to 1K WebP; geometry is meshopt compressed. Authored trigger/grip/fore-end/rail/iron-sight/muzzle anchors and moving parts are fitted to the game. Additional magazine bodies, drum detail, bipods, iron-sight mounts, optic risers, projected surface grain and chassis parts are Last Zone FPS adaptations. The fictional names do not imply exact replicas: AR-416/SR-25/LM-86 use AR-family bases, SG-56/MS-56 use SIG MCX-family bases, DM-56 uses SCAR-L, CX-9/MP-9 use MP5-family bases.

Distribution adaptations: neelsatyavolu/ironvale (part separation, display-prop/optic removal, material/geometry preparation); cktang88/3d-fps (first-person part separation and texture atlases); ossama450298-commits/BLACKSITEVECTOR (prepared/optimized DJMaesen and user77 GLBs); segmentt61/undead-ops (prepared SPAS-12); joaoCasella/FPS (BarcodeGames FBX distribution). Their imported artwork retains the licenses and artist credits above. Only artwork and sampled animation data are imported, not code from those games.

## Reload animation attribution

- **BarcodeGames**: [Kriss Vector Animated( Free)](https://skfb.ly/6RKL7), FBX `Armature|Reload|BaseLayer`; Blender export clip `Animation`.
- **DJMaesen**: [fps animated smg](https://sketchfab.com/3d-models/fps-animated-smg-ea3dad7478624495a5a46f40127b0579) and [lmg animated](https://sketchfab.com/3d-models/lmg-animated-c02dc6663f344008a502148e751c9974), `allanims` reload intervals.
- **AetherRadar / operation-steel-tide**, adapted by **cktang88 / 3d-fps**: `animated_reload_arms.glb` platform clips (MP5, M4, AK, SCAR, M24 and P226), derived from DJMaesen’s licensed arms and animation artwork. [Derivative provenance](https://github.com/AetherRadar/operation-steel-tide/blob/main/assets/models/djmaesen_smg45/LICENSE.md).
- **Cransh**: [FPS Arms remington (shotgun)](https://sketchfab.com/3d-models/fps-arms-remington-shotgun-e68ef617fe8a48cca8610d016ffd5881), reused licensed shell-loading curves for SP-12; [existing provenance](../../animations/reloads/CREDITS.md).

Changes: wrist/gun curve extraction at 60 Hz, coordinate conversion, semantic-event time warping, constrained retargeting to the existing two-arm IK rig, per-shell cycling, and separate tactical/empty mappings. The downloaded skeleton is not a drop-in fit for every gun: magazine, pump, bolt, feed cover, belt and contact actions use fitted game-specific mechanisms. MG-60 has an independent cover/box/belt sequence. Models without an exact matching source animation use a compatible platform motion.

Machine-readable source URLs, immutable revisions, SHA-256 checksums, model adjustments and per-weapon clip mappings: [`tools/guns/expansion-sources.json`](../../../tools/guns/expansion-sources.json). Runtime curves: [`expansion.json`](../../animations/reloads/expansion.json). No external asset service is contacted during play.

## Rebuild

```sh
python tools/guns/fetch-expansion-assets.py /path/to/sources
blender -b --python tools/guns/prepare-expansion-vector.py -- /path/to/sources
# Node dependencies: three@0.160.0, @gltf-transform/{core,extensions,functions}@4.4.1,
# meshoptimizer@0.23.0, sharp@0.34.5 (set NODE_PATH if installed elsewhere).
node tools/guns/import-expansion.cjs /path/to/sources
node tools/guns/extract-expansion-reloads.cjs /path/to/sources
```

The shared in-game hand rig retains its existing [viewmodel attribution](../viewmodels/CREDITS.md). Platform grip-template references, including Cransh, are also credited by the upstream derivative projects.
