# Attachment model credits

- `weathered-scope.glb`: [Rifle Scope](https://opengameart.org/content/rifle-scope) by LonesomeDucky, CC0. Converted from the original Blender file to glTF binary; textures resized to 512 pixels and compressed.
- `micro-dot.glb`, `red-dot.glb`, `holo.glb`, `magnifier.glb`, `vertical-grip.glb`, `suppressor.glb`, `laser.glb`: [Flat Gun Attachments](https://pichuliru.itch.io/flat-gun-attachments) by Pichuliru, CC0. Original glTF binary models; scaled and positioned in the game. These are stylized, low-poly models.

Both sources identify the assets as CC0: https://creativecommons.org/publicdomain/zero/1.0/
